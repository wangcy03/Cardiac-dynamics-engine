2. 三条第一性原理：守恒、动量、储能

2.1 血液不能在连接处凭空出现

对任一控制体，容积增长等于流入减流出。在封闭循环中，一条连接转移多少血液，就必须从上游减去同样体积、给下游加上同样体积。把所有结点相加，内部连接逐对抵消。持续状态因此携带前面所有心搏和干预的后果。

(1) 有限体积质量守恒
dVidt=∑入Q−∑出Q,ddt∑i=1NVi=0\frac{dV_i}{dt}=\sum_{\mathrm{in}}Q-\sum_{\mathrm{out}}Q,\qquad \frac{d}{dt}\sum_{i=1}^{N}V_i=0

这里暂不含球囊；含球囊时要按第 4 节扣除占据体积。血液密度取常数，因此质量守恒可以直接写成血液体积守恒。

LaTeX 源码

2.2 压差先改变动量，流量不必立即翻转

把一段流体的平均惯性写成 L，把黏性损失写成 R，得到 RL 连接。正的压差推动流量，阻力消耗机械能；只要 L 为正，压差突然反向后，原有正流量仍可短暂继续。这解释了为什么“压差反向”和“流量过零”是两个事件。

2.3 血管壁储存能量，心肌主动提供能量

液体近似不可压缩，不意味着循环不能储血。容积变化主要来自壁的变形。在线性顺应性元件中，C 表示压力增加一个单位所增加的容积；伸展血管壁需要做功，壁回缩时释放这部分弹性储能。主动心肌还有随时间改变的主动项，因此它不是纯被动弹簧。

这些局部恒等式提供设计检查：R ≥ 0 不应自己产能，内部流量不应自己造血。当前项目尚未完成全系统能量账本与所有源项的离散能量核验；不能把极小的总血量残差等同于所有物理量都正确。

3. 当前 0D：一套持续状态，九个有限容积

当前拓扑按血流方向闭合：LV → 主动脉根部 → 降主动脉 → 体静脉 → RA → RV → 肺动脉 → 肺静脉 → LA → LV。它没有固定左房压力池。每个容积有限，所以一次射血不足、回流变化或球囊干预会延续到之后的心搏；代码不在每搏开始时重置容积或套用同一条周期曲线。

6. 独立 1D：让压力与流量沿空间传播

B01 先把心脏和球囊拿掉，在均匀弹性管中单独验证传播。沿管长 x 的每个截面有面积 A 与体积流量 Q，平均速度 u=Q/A。第一切片采用 α=1、固定参考几何、常密度与纯弹性壁；空间变参数、壁黏弹性、球囊源项都不能在没有推导的情况下顺带加入。

7. 方程正确，还要证明怎样被近似求解

7.1 当前 0D 的整体方法并非“处处解析精确”

先用旧状态做半步预测，再用中点预测的压力／开口系数做一次全步。每条 RL 连接在冻结系数下解析计算端点流量和积分体积，激活、开口和一阶球囊也解析推进。系数在全系统中仍随时间变化，所以整体属于分裂的中点方案；局部解析不等于耦合系统解析解。

0D 每步不超过 250 μs，并按事件、采样和交付边界再细分。独立 SciPy Radau 参考核验的是“同一组 0D 方程是否被近似一致求解”，而不是“这组方程是否代表患者”。改变异步采样配置也可能改变积分切分，需要把它造成的细小数值差与真实生理差分开。
