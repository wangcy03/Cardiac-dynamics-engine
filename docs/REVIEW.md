# 本轮代码自审（非独立第三方审查）

审查基线：r1文档包（无生产求解器）。本轮为新建项目，不虚构Git merge-base/远程提交。
范围：iabp/、tests/、examples/、tools/；宏观依据为r1、AGENTS与ARCHITECTURE。

## Standards 轴
- 核心不依赖UI/网页；生产核心仅标准库。所有算法可见数据通过冻结Sample传递。
- 独立随机源、整数时钟、真实流量积分、正负压差、显式失败已实现并有对应测试。
- 原始r0/r1和旧页面按字节保留；未写入凭证/真实身份/外部账户信息。
- 快照和未来队列完整，但仅进程内，不是跨版本文件格式。长运行历史未裁剪，属于B02。
- 静态工具无法联网安装；mypy/ruff未运行，不能给出“全部质量门通过”。B00需补。
- UI核验是在浏览器直接渲染给定HTML内容，未绕过本机file://策略；用户打开路径行为未在该策略下验证。

## Spec 轴
- M0主要路径落实；还没有真实监护仪批缓存/抖动/二阶导管/进程隔离。
- r1 §5 的完整0D/1D路线未全部实现；当前0D仅桥接基准，B01/B04仍是硬依赖。
- r1 §5.3 的球囊血量修正和保持阻塞已有原型；单点阻塞和一阶动作未达到台架验证条件。
- r1 §7 全指标共同参考窗口/二维扫描未实现；示例只导出原始窗口指标，不给临床通过判定。
- 无新高保真独立数据，T16/T20等保持BLOCKED_DATA，不能由程序稳定性替代。
- 有效开口闭合、流量过零、压差反向分别记录；没有补切迹/闭瓣固定时刻。

## 数值审查中处理的问题
第一轮简单单级激活造成过快的压力建立。改为有明确微分方程的两级有效激活，

没有在显示端抹去振荡，也没有把调参作为生理验证。

结论：可作为透明、有证据的原型交接；不是最终完整引擎或临床校验器。
