# 固定迭代观察器

观察器是实际导出记录的查看器。维护源在 `viewer/`，兼容便携入口仍为
`artifacts/demo/prototype_viewer.html`。每次运行复用同一套 HTML/CSS/JavaScript；
Python 适配器只读取原始数据和身份记录，不求解另一套生理波形。

## 三个视图

- **心脏/时序**：真实导出的压力、流量、四腔容积、瓣膜开口、激活和球囊；
  按物理/源/交付时钟分别读取采样，列出实际事件和命令状态，绘制真实 PV 轨迹。
- **独立 1D**：匹配传播、反射、分叉及公开 Boileau 数值参考；可选套件、方法、网格和剖面时刻。
  历史低精度结果、负振铃和缺失字段保持可见。
- **迭代比较**：选择或拖入冻结包作为 A/B，比较共同物理时间上的原始信号、指标和配置。
  缺初态/源码身份时明确显示未知，不能从波形差值推断生理改进。

时间缩放、轨道开关、双游标和显示抽样只改变阅读方式。
指标仍使用已声明的完整记录窗口；读取游标用原样本，不由显示折线反推数值。
Boileau 八个实际时刻的空间剖面不能作为连续探针时序。

## 只刷新已有记录

从项目根目录执行：

```text
python -m tools.viewer --label "本轮模型的实际导出"
```

命令读取现有 `artifacts/demo/`、`artifacts/arterial1d/`，创建唯一的
`artifacts/runs/<run_id>/`，保存原始文件副本、`manifest.json` 与 `viewer_bundle.json`，
再更新兼容 HTML 和当前 JSON。相同 run ID 已存在时拒绝覆盖。
完整字段与来源语义见 [数据合同](DATA_CONTRACT.md)。
本轮实际命令、测试映射、数值差异和未验证项见 [V1 核验记录](ACCEPTANCE.md)。

需要预载历史对照时：

```text
python -m tools.viewer --comparison artifacts/runs/<历史run_id>/viewer_bundle.json
```

历史包也可通过界面文件选择或拖放加载，无需网络请求。
`viewer/index.html` 是不带固定运行数据的长期入口；便携 HTML 内嵌同一套界面及当前真实数据。
`--no-freeze` 只刷新临时预览，不保存新的冻结目录。

## 模型真的发生变更时

先按任务完成模型测试与数值核验，再执行：

```text
python -m examples.run_demo
```

该命令运行既有 0D 演示并更新原始导出，然后调用同一适配器冻结和刷新观察器。
它不会自动重跑独立 1D；1D 原始记录仍需通过自身的身份核验。
模型未变、只有观察器变更时，直接重读已有记录即可。

## 当前适用域

0D 心脏与独立 1D 尚未耦合；B01 新增传播能力不应让原有 0D 波形发生人为变化。
现有 AP_MONITOR 不暴露源时间、原始命令日志不含完整动作目标；界面保持缺失。
旧 provenance 只记录 model.py 源身份，不能升级为完整运行源码/Git 身份。
当前进程内共享快照与首行一致，不等于跨版本初态已被证明一致。

原始 r2 → 当前 0D 的对照主要是平台/数值复现，差异可能仅为浮点末位。
旧 1D 方法不满足门槛的记录继续保留，与当前方案分别归属。
软件、独立数值参考与临床验证分别报告。

本会话浏览器工具此前拒绝本地 file 协议并禁止绕过，因此本轮浏览器渲染仍须如实记录未运行。
Python/Node 测试或生成成功均不能代替实际布局和交互验收。
