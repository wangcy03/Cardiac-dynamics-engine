## 每项任务提交模板
目的 → 改动的方程/接口 → 明确的测试和容差 → 原始结果文件 → 数值差异 → 未解决项 → 下一张票。

## 并行边界
B01 只维护传播模块及其基准；B02 只维护协议/调度/日志；B03 维护心脏本构。
共享事件词典、单位、contracts.py 的变动需先协调。独立分支/工作树合并前重跑全部回归。
不允许多个任务各自创造不同的 AC 定义或者用自己的“正常波形”充当共同真值。

## 需回本会话/负责人决策
用途升级为正式验证/注册；改变最终架构或事件真值；风险/效果阈值；新的大模型假设；
真实设备边界不兼容、5ms目标需要修改。一般类型标注、优化和测试扩展由 Codex 直接推进。
