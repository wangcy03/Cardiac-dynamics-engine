## 3. B03b：全局机械能量账本

### 定义先行

第一切片限定常外压、固定连接惯量和当前心腔本构。所有压力/功使用同一参考与单位。
血量守恒、机械能量平衡和患者代谢能量是三个不同对象。

从已实现方程逐项推导储能与功，不使用经验修正项把残差抹为零：

```text
被动腔室：U_pass(V) = ∫ P_pass(V) dV
恒定惯量连接：K = 1/2 · L · Q²
连接功率：ΔP · Q = dK/dt + R(z) · Q²

若 P_active = E_active · a · (V − V0)：
U_active = 1/2 · E_active · a · (V − V0)²
∂U_active/∂t|V = 1/2 · E_active · (V − V0)² · da/dt
```

最后一项是该降阶本构中的主动状态储能交换，可正可负，不能当作已验证的心肌氧耗。
若后续本构不具备这个储能形式，须重新推导而非沿用。

总残差采用：

```text
r_E = S(t) − S(0) − W_active − W_boundary − W_balloon + D
```

其中 S 包括模型实际表示的腔室/血管储能及血流动能，D 是实际阻性耗散积分。
无球囊首域 W_balloon=0；闭环常外压下边界功按控制体核算，不能因“闭环”漏掉主动或外压功。
需要球囊时以当前控制体重新引入功，不由该票预先声称气动能量已闭合。

### 数值预算与报告

本票新增预算均为工程验收提案，先冻结配置/归一化尺度再执行，不是人群正常值。
- 相邻容积结点必须使用同一个积分转移体积；相同界面两侧不能独立积一次再声称全局守恒。
- 基础闭环质量残差预算：相对初始总血量 ≤1e-8；同时报告 mL 绝对值和长窗口漂移。
- 总能量归一化尺度预先定义为最大储能变化与各功/耗散绝对量的组合，包含明确的有单位绝对下限，避免近零分母。
- 细档归一能量残差初步目标 ≤0.1%；三步长应显示收敛或达到舍入误差区。未满足先定位，不放宽。
- 能量收支的输入、各项积分和残差原样导出。独立参考同时解同一方程与积分账本，不能读生产残差作为答案。

### 必测用例

H-W01：被动 RC/RL 或当前元件解析试验，检查储能衰减与非负耗散。
H-W02：无主动驱动/球囊的闭合被动网络，不出现无来源机械能增加。
H-W03：有主动激活的完整非辅助循环，主动项与储能/耗散闭合。
H-W04：有限窗口含过渡时，不能把窗口功自动称为闭合 PV 环面积。
H-W05：独立 Radau 参考与生产方法在相同输入/时间上的状态、功、残差对照。
H-W06：三个步长，所有失败与状态不合法情况记录；不做压力/容积 clipping。

## 4. B03c：短间期与恢复结构试验

在 B03a 的定义上，加入稳定节律、提前激活、间歇、再次激活的外生事件序列。
工程扫点可从 RR=1000/833.333/600 ms、相对基准的短间期比0.5/0.7/0.9开始；
这些只是结构测试，不称临床早搏分布。负荷扫点从当前声明参数的0.75/1.0/1.25倍开始，
每一组合先检查参数合法性及参考状态，不能只筛选符合预期的结果。

记录前后搏激活/恢复、充盈、EDV/ESV、SV、LV压与事件。需要证明历史有影响，
不强制所有短间期都出现同一倍数增强。不能用“恢复变量存在”作为PESP已验证的依据。

若固定激活起止不能覆盖目标域，先提交基线失败图和最小候选方程/参数证据，
按现有 ADR 规则请负责人确定是否改变生理假设；不得为匹配一个切迹时间随意调机械驱动。
