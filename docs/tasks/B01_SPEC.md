# B01 可执行任务规格：独立一维传播模块

## 目的与边界
先验证无球囊、无心脏的动脉传播器，后续B04才与心脏连接。不能先接UI并调到波形好看。
当前冻结的是独立基准的工程选择，不声称以下参数来自患者。

## 第一切片的方程和单位
内部采用SI：A[m²]、Q[m³/s]、P[Pa]、x[m]、t[s]、ρ[kg/m³]。
在一段均匀、无分支管内，第一切片令速度分布修正α=1、刚性参考几何：

    ∂A/∂t + ∂Q/∂x = 0
    ∂Q/∂t + ∂(Q²/A + Π(A))/∂x = Sf
    P = P0 + β*(sqrt(A/A0)-1)
    Π(A) = β*A^(3/2)/(3*ρ*sqrt(A0))
    c² = A/ρ*dP/dA = β/(2ρ)*sqrt(A/A0)

先做Sf=0的独立波基准，再加入声明的粘性阻力。可选的准稳态Poiseuille项为Sf=-8πνQ/A；
采用α=1同时使用此阻力是降阶近似，须在模型说明中保留，不称精确三维速度分布。
A0/β/P0沿空间变化时会出现几何/本构源项；未推导前第一切片只支持分段均匀管段，不静默外推。

## 数值默认
有限体积守恒，先用Rusanov通量及对应边界特征量；CFL初值0.4。
使用局部特征速度u±c。保持A>0；不通过截断负面积制造合法解。
返回显式步长限制与失败信息。需要高阶时另立对比，不覆盖基础基准。

## 工程测试配置
- L=1m，A0=3e-4m²，ρ=1060kg/m³，c0=5m/s，β=2ρc0²=53000Pa。
- P0仅是参考压力，可以选0Pa；不把该配置当作人体患者。
- 初态A=A0，Q=0；小振幅入口压为0.05~0.09s的20Pa正弦平方脉冲，其余为0。
- 匹配端特征阻抗Z0=ρc0/A0。小信号参考p(x,t)=pin(t−x/c0)。
- 反射用例：末端封闭Q=0得到线性Γ≈+1；压力释放端Γ≈−1；Rterm=2Z0得到Γ≈1/3。
- 对称分叉：两子管A0各为母管一半，c0相同；线性匹配条件下近似无净反射，Q各一半。

入口要按特征边界注入，不同时强制不兼容的P和Q；末端与分叉也必须保持特征数量和流量守恒。
分叉初期采用无局部损失共同静压近似，明确忽略动压与几何损失；之后需要换总压方案则补ADR和基准。

## 三档收敛
至少80/160/320个网格，dt满足各自CFL。报告压力最大差、脉冲到达时刻、反射系数、
积分体积误差及随网格变化的阶次；任何对齐平移只能单独分析，不用于误差合格计算。
小振幅基准建议到达差≤0.5ms、峰值相对差≤1%作为细网格候选门槛；若网格仍不足应细化而非改答案。
这些门槛是工程核验，不等同0.5ms生理事件精度。

## API与交付
建议独立模块 `iabp/arterial1d/`，输入管段/边界，输出状态、可接受步长、通量、压力采样。
此时不得依赖网页、控制器或带球囊的假源项。SI与既有mmHg/mL接口建立集中转换和测试。
提供tests、基准CSV/JSON、参数来源/单位和图。公开Boileau基准输入需实际下载、核查许可并保留哈希；
未取得前相应外部基准状态仍为BLOCKED_DATA，不阻挡上面的解析基准。

## 禁止的提前完成声明
这不是IABP模型，也没有验证真实根部切迹。球囊进入时有效血流面积Aw−Ab与动量源需在B05重新推导，
不能只把当前A改名后重复添加dVb/dt，或将球囊效应当作压力高斯峰。
