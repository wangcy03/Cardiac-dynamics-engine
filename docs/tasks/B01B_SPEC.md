# B01b：为耦合准备的 1D 传播适用域扩展

这是已完成 B01 的扩展票，不否定或覆盖原 [B01 报告](B01_REPORT.md)。
状态见 [BACKLOG](BACKLOG.md)。前置：B00/B01 基础与 C00 当前基线核查。

## 1. 原因与不做什么

现有声明域含光滑小幅工程脉冲与公开 Boileau 无黏性参考。
高阶 linear3 非 TVD；通过该域不能证明较快、较大或反向扰动均可靠。
本票回答“哪些网络工况可以接 B04a”，不是先人为制造切迹，也不添加球囊。
主要所有权：`iabp/arterial1d/`、`tests/test_arterial1d*.py` 与独立基准工具。

## 2. 先冻结输入与范围

沿用 [B01_SPEC](B01_SPEC.md) 的守恒方程、单位、参考管几何与边界定义。
平均压力改变时必须通过同一本构求一致面积和参考状态，不能只把输出加一个压力偏置。
平均流量初态需要与黏性压降/边界一致；不是在原零流稳态上随便加 Q。

下表是建议的**工程扫点**，不是生理人群范围，也不是已通过工况。先写可机器读配置并固定哈希。

| 维度 | 首批选点 | 限制 |
|---|---|---|
| 压力脉冲幅值 | 保留20 Pa旧基准；新增±5、±20、±40 mmHg | 不合法跨壁压/面积组合预先显式拒绝；不从统计中隐藏 |
| 平均参考压力 | 60、90、120 mmHg | 指定外压与P0，保持本构自洽；不能直接视作患者 |
| 时间尺度 | 平滑脉冲过渡约10、30、60 ms | 定义支撑区间和端点连续性，不用不光滑阶跃误当纯传播误差 |
| 平均流量 | 0、约80 mL/s的稳态基线；另设衰减过零/短暂逆流 | 有限域内保持亚临界；超临界先显式不支持 |
| 边界/拓扑 | 匹配、压力释放、封闭、既有阻性反射、对称分叉 | 不改变现有共同静压近似；新总压/损失模型另提案 |

先单因素，再挑耦合将用到的组合和重复反射；不必先全笛卡尔积。
B04a 只可使用已验收的组合及保守内插域，不将单因素通过扩大成所有组合通过。

## 3. 方法和参考答案

保留 Rusanov、MUSCL、linear3 三条独立结果，新增方法另命名。
小信号域可用解析特征波/反射系数；大幅非线性域不能拿固定波速平移当“精确解”。
非线性域使用已推导的简单波/守恒关系（适用时）与独立实现、细化网格交叉参考。
只比较同一个求解器两档网格可叫自收敛，不能单独称独立准确性验证。

最少三档空间分辨率（初步160/320/640，必要时继续细化）与至少三档时间控制。
不能仅令 dt 随 dx 等比例缩小就同时宣称空间和时间误差已分别辨识。
先在细网格扫时间，再在时间误差受控时扫空间，最后检查合并预算。

## 4. 测试与失败判据

| ID | 测什么 | 判据与输出 |
|---|---|---|
| W-D01 | 旧B01回归 | 原输入/门槛/失败原样保留，不能覆盖 |
| W-D02 | 正负/快慢非线性脉冲 | 相同物理坐标压力、流量、到达时间与独立参考，不对齐/归一化掩差 |
| W-D03 | 逆流与重复反射 | 边界特征方向、事件过零和体积账本正确；不支持时显式失败 |
| W-D04 | 分叉 | 各RK阶段及整步通量收支、压力条件一致，累计残差完整导出 |
| W-D05 | 合法性/失败原子性 | A>0、有限状态、CFL/源项限制；失败不提交半步状态；禁止clipping |
| W-D06 | 人工极值 | 定义无局部凹点的参考输入/解，比较新极值数、幅度和位置；保留每种网格振铃 |
| W-D07 | 时空收敛 | 波形误差与事件数/身份均有记录；细档压力差≤0.5 mmHg、事件差≤0.5 ms作为r1预算 |

人工切迹风险必须定量：在预期单调区间识别新极小值及其回升幅度，
分别报告原始极值和超过预先固定噪声/幅度门槛的极值。阈值不能按结果移动。
若伪凹点足以越过将来的事件检测门槛，该方法/网格组合不进入该检测用途的通过域，
即使整体压力误差小于0.5 mmHg也不算合格。不要先平滑再计算数值准确度。

守恒建议沿用相同界面积分账本；累计误差归一化同时报告绝对mL与相对初始储血量。
无事件、事件合并、反射时间窗尚未覆盖、参考缺失、非法输入与数值失败分别统计。

## 5. 交付合同

建议新增工具/测试模块可以另命名，但以下产物语义必须存在：

- 预注册参数/边界/方法/网格/容差配置。
- 每run原始CSV/JSON、实际命令、源码/环境/输入身份及失败日志。
- `validity_domain`：已通过范围、明确拒绝/未测范围、允许的步长/网格、参考方法、假极值限制。
- 独立报告及原理文档对应假设更新，现有工具增加适用域感知而不把旧PASS泛化。

本票不会产生 IABP 球囊传播数据或根部关闭真值。B04a 开始前必须能读到明确的已通过子域；
若尚无满足预算的方案，保持阻塞，先扩大网格/验证新方案，不能以“看起来平滑”批准耦合。
