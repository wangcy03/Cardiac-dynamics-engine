# B02：协议、可移植快照与长运行可靠性

状态见 [BACKLOG](BACKLOG.md)。本票可与物理模块独立并行，不要求先完成1D耦合。
真实设备协议仍属B06；本票实现工程合同，不能虚构某一监护仪格式。

## 1. 不变边界

沿用r1的可见Sample/命令合同：设备源时钟、引擎物理时钟和样本可用时刻分开；
未知源时刻保持未知，算法不可读取隐藏传感器映射、未来电事件或模型真值。
Python对象接口并非恶意代码沙箱；跨进程能减少误用，但也不等于完成安全隔离认证。

## 2. B02a 可移植快照

在现有同进程deepcopy行为之外加入有版本的显式数据格式；禁止反序列化不可信pickle。
快照至少包含：连续物理状态、激活/恢复、瓣膜、球囊/执行器、所有时钟、事件和命令队列、
传感滤波状态、每通道RNG、样本交付序列及消费游标，以及足够的模型/配置/schema身份。
尚未实现的1D/新物理状态有明确扩展点；不得把漏保存的状态默认为0。

同schema/同模型版本跨进程恢复是第一目标，不先承诺任意跨版本迁移。
版本不支持、配置不符、非有限数、单位缺失、尺寸超限或恶意字段应明确拒绝且不改已有引擎。
迁移转换器另行版本化和测试，不能静默“尽力恢复”。

验收：同版本新进程恢复后，相同输入/RNG产生可重复样本、事件、命令和轨迹；
跨平台允许事先声明的浮点容差，但事件次序/缺失语义一致。
快照失败不留下半保存文件；处理大文件和损坏输入时不允许无限内存分配。

## 3. B02b 外部控制器合同

可先用版本化JSONL收发。记录协议版本、序列号、单位、可见时刻、允许动作、接受/拒绝/开始/完成状态。
只有已交付样本可发送给算法；超时、阻塞、进程退出、重复/迟到/乱序命令分别回归。
取消仅影响未开始命令，反向动作必须经过执行器动态，不得直接清空物理状态。
同时间事件顺序沿用既有契约；新增策略有显式配置和日志，不猜真实控制台行为。

隔离测试：替换未来节律、注入测量单路故障、切换采样分批边界，确认过去不变与命令因果性。
不得把“外部控制器使用模型真值的oracle”误标成因果演示控制器。

## 4. B02c 长运行与内存

日志使用有界缓存或流式输出；消费/丢弃策略明确。真值可流式保存，控制器队列不得无限增长。
压力测试可分：至少10^6条样本的快速调度/队列测试，以及较长模拟时间的集成运行；
前者不是生理长时稳定性测试，后者报告实际墙钟、模拟时长和资源峰值，不先承诺实时速度。
报告队列上限、内存随记录量斜率、丢样/背压、快照大小及恢复耗时；有界队列满时策略可追踪。

## 5. 子项验收

| ID | 试验 | 不可接受结果 |
|---|---|---|
| P-01 | 跨进程保存/恢复，包括RNG/滤波/队列 | 恢复后无来源的第一搏差异或重复命令 |
| P-02 | 坏schema/截断/过大/不匹配配置 | 接受伪数据或覆盖有效状态 |
| P-03 | 进程阻塞、退出与超时 | 无限等待或悄悄把球囊置零 |
| P-04 | 同时事件、取消、反向、迟到/重复 | 事件次序不确定或执行日志缺失 |
| P-05 | 未知源时间与物理真值隔离 | 用隐藏时钟/故障真相帮助算法 |
| P-06 | 长队列/流式审计 | 只因记录时长增加而无限内存增长 |

交付入口及实际运行命令随实现写入报告；本规格不假定新的序列化API已经存在。
只修改协议/调度相关文件，需物理模块新增可导出状态时先协调，避免两个分支同时重构同一核心。
