# B08a：立即启动的数据准备与台架证据计划

这是B08的前置工作流，不等同于生理验证已开始或通过。
状态见 [BACKLOG](BACKLOG.md)；唯一数据缺口主表沿用 [DATA_GAPS](../DATA_GAPS.md)，
来源沿用 [SOURCES](../SOURCES.md) 与 [r0](../reference/research_r0/IABP_Physics_Engine_Design_r0.md)。
本文件规定采集/获取工作，不复制一份会漂移的数据取得状态。

## 1. 数据包分层与对应结论

| 包 | 最需要的同步量 | 能支持什么 | 单独不能支持什么 |
|---|---|---|---|
| D-PHY 无辅助基线 | ECG、已知测点AoP、LV压；尽可能有流量/容积与独立瓣膜参考 | 事件、激活/负荷与多信号生理基线 | IABP干预反事实、执行器动态 |
| D-ACT 执行器/球囊 | 命令、实际Vb或独立标定代理、局部AP、气压/气源、两端流量 | 命令→动作、负荷依赖、排挤/阻塞 | 人体心肌/冠脉长期效应 |
| D-SENS 三类AP与直接ECG | 共同参考输入、原始/交付样本、设备时钟、滤波/缓存配置 | 位置与仪器动态分离，链路标定 | 未测解剖点的真实传播 |
| D-INT 时序干预 | 上述关键通道+辅助比/时序改变+负荷背景 | 校验方向、效应幅度、残余阻塞和恢复 | 无独立分组时的泛化结论 |

先获取少量可追溯、多模态、带干预的记录，比堆叠大量不知测点的AP更切题。
公开文章说明有数据，不等于已下载；高采样率不等于已知频响或已知同步精度。

## 2. 每份数据必须有的清单

数据/受试者或动物去标识ID、物种/工况、测点解剖位置、传感器类型、采样率/单位/增益/零点、
原始时间戳与同步方式、仪器滤波/频响、源和交付时间语义、缺失/饱和/伪迹、命令/动作定义、
许可/同意/使用限制、原始文件哈希、处理代码版本、校准与独立验证分组。

主动脉瓣关闭、流量终止、压力谷底、导数极值各自定义。不能用同一条AP生成标注又证明该AP算法精确。
5 ms目标需要参考同步和标注不确定度一起报告；不能把125Hz插值当独立毫秒真值。

## 3. 台架建议（研发方案，待实际设备边界确认）

从现有球囊名义30/40/50mL工程范围中按实际产品选择；记录实际占据容积而不仅是气源排量。
扫描局部血压、充/放气速度、气路/导管、保持状态、角度、未完全排空和重复动作。
命令、气体压力、Vb代理和血液侧信号共时钟或经独立同步校准。
先验证单独排挤/保持阻塞，再验证周期与非周期命令；各项的风险和装置限制由实验负责人审批。

协议不能仅规定“切迹后充气”：应给原始命令、动作、根部/局部压力与参考事件，便于重新分析。
已经取得的真实设备参数不与工程默认混写；未知项保留未校准。

## 4. 分工与解除阻塞

Codex：整理现有来源、下载有许可的公开数据、核验格式/时钟/单位/哈希，建立加载和质控测试。
项目负责人/实验方：提供实际测点与设备链路、台架条件、访问协议与安全审批，以及认可的参考事件定义。
不得索要或在公开仓库保存患者身份/凭证；受限原始数据不推送，只登记可公开的元数据/校验信息。

每个缺口写清：影响哪一条结论、可继续哪些工程票、下一动作、负责角色、解除条件和证据位置。
来源访问失败写取得失败，不自动换成截图描线或不明外周ABP冒充根部真值。

## 5. 本票完成不要求全部数据已取得

完成条件是：每类必要证据有可执行方案和追踪项；已取得者通过完整性/单位/许可核验；
未取得者有明确状态和解除路径。只有实际完成校准/独立验证，B06b/B07b/B08才能各自升级状态。
数据准备不阻塞B03/B01b/B04a工程推进，缺失的生理资格也不会随工程推进自动获得。
