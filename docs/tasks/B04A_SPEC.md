# B04a：无球囊的最小 0D/1D 双向闭环

工作状态与依赖见 [BACKLOG](BACKLOG.md)。前置工程门：B03a、B03b、B01b 的声明窄域。
接口设计和隔离测试可先做；未通过前置门不得把接入生产链记为完成。
本票是 B04 的第一切片，不代替 B04b 的解剖网络/测点扩展。

## 1. 目标与非目标

证明：心室/主动脉瓣与单段1D血管通过同一压力—流量边界相互作用；
改变下游负载能改变上游压力、流量和动态瓣膜状态，且质量/能量账本成立。

不加入球囊，不校准患者，不用根部波形固定平移生成其他位置，不重构观察器。
保留原0D后端为独立回归基线，新联合后端单独命名，不能覆盖原CSV后宣称原模型“改善”。

## 2. 拓扑与储血替换表（写代码前完成）

第一张接口图可采用：现有心脏/回流 → 主动脉瓣 → 单根1D管 → 有状态末端负载 → 原有限回流。
单边固定压力池只用于接口单元试验，不能把其质量收支称为完整闭环通过。

逐一列出旧0D结点在新拓扑中的处理：保留、替换或显式接口小腔室。
如果1D已代表根部/降主动脉的储血与顺应性，不得在同一空间又保留旧结点的相同储血/顺应性。
若保留近端腔室，必须说明其实际表示的独立空间/顺应性，不得仅为调出好看的切迹。

总血量按下面同一控制体计算：

```text
V_total = Σ V_0D_retained + Σ_cells A_i Δx_i + V_terminal_storage
```

本票无球囊，不含 −Vb。末端若已作为保留0D结点，不得再次加 V_terminal_storage。
固定几何死腔可以记常量，但初态映射必须一致。映射测试优先保证物理血量，不保证原模型波形完全相同。

## 3. 单位和耦合条件

0D使用mmHg/mL/s，1D使用SI，所有换算集中调用 `iabp/units.py`，接口时钟仍是整数微秒。
每个边界必须声明法向、Q正方向、压力参考和时刻。

单边界所需关系来自：
- 1D 域内传到边界的出射特征；
- 0D 状态/动态瓣膜提供的关系；
- 必要的接口压损和一致的边界流量。

不能同时独立指定不兼容的边界P和Q；不能先跑完0D一搏、再把流量文件喂给1D冒充闭环。
边界求解在实际阶段时间上取值；子迭代未收敛时失败，不接受“最近一次看起来合理”的状态。

界面双方必须共享同一个积分转移量：

```text
ΔV_interface = ∫_[tn,tn+1] Q_interface(t) dt
ΔV_0D = −ΔV_interface
ΔV_1D,interface_contribution = +ΔV_interface
```

若有子步/RK阶段，使用实际权重和面通量，不用步末Q乘dt替代实际积分。
每条边界均导出该量；数值面通量与边界状态取值的差异不能被隐藏。

## 4. 能量与求解调度

B03 的能量账本扩展到1D血流动能和血管壁储能。连续动量/能量通量包含动能输运时，
不能仅用P·Q报告完整能量；在相应假设下至少核查 `(P + ρu²/2)Q` 与采用的壁本构。
实际模型、几何、黏性或接口损失改变时重新推导，不将该表达式当所有模型的通用公式。

接口两侧功使用同一压力参考/积分规则；任何忽略动压的接口近似必须给出适用范围和误差。
本票若需要改变已有共同静压分叉/边界假设，应先提ADR，不在耦合过程中静默升级。

调度建议分两步：
1. 同步小步参考实现，步长同时满足0D事件边界、1D CFL和源项限制。
2. 参考通过后再评价子步/多速率优化；时间精度、守恒和状态应与参考比较。

失败原子性必须覆盖0D、1D、瓣膜、终端、调度时刻和排队事件。失败后重试不能重复执行一次电激活或命令。
不要在生产状态上试算半步、失败后只回滚1D数组。

| ID | 设置 | 验收要求 |
|---|---|---|
| J-01 单位/符号 | 给定双向边界体积和压力 | mmHg/Pa、mL/m³、μs/s双向转换正确，界面两侧符号相反 |
| J-02 静态平衡 | 无驱动、平衡压力、零流 | 无无来源脉冲，初态血量与储能映射一致 |
| J-03 被动脉冲 | 闭环或明确开边界单元试验 | 质量账本及被动能量耗散正确；开边界功/流量计入 |
| J-04 双向反馈 | 同一快照，仅改变末端阻力/顺应性 | 下游影响可在传播后到达上游，并影响LV/Q/开口；不能只改变一条显示曲线 |
| J-05 反馈因果性 | 只改变未来时刻终端输入 | 该时刻之前的状态/样本不变；不得用未来边界状态 |
| J-06 闭环收支 | 恢复完整有限回流；连续运行 | 无重复储血；累计界面差与全局质量残差受预算约束 |
| J-07 失败恢复 | 故意使边界不收敛/CFL违规 | 整步失败、全状态不提交、旧有效状态可继续复现 |
| J-08 时空精度 | 三网格×三时间控制档 | 在固定物理时间和同一事件身份下报告波形/事件/守恒/能量误差 |
| J-09 关闭期局部波形 | 输出LV、根部P、Q、开口与导数 | 谷底只能标候选；无谷底保持无；数值振铃不可补成生理切迹 |

负载扰动优先取当前声明阻力/顺应性的0.8/1.0/1.2倍；不是临床处置建议或患者范围。
同时记录扰动是否改变其他储能/容积初态，禁止用重置状态伪装真实干预。
首个瞬态比较从同一快照分叉；持续各自稳态的比较另列，不能混名。

## 6. 工程精度与入口门

沿用r1：细化后的主要压力轨迹数值差≤0.5 mmHg，关键模型事件数值差≤0.5 ms，
这不是生理误差。只有共同事件存在且身份一致时才能算时差；漏检/事件拓扑变化单独失败或不确定。

新接口预算提案：共享积分体积的两侧记账在舍入误差内一致；全局血量相对漂移≤1e-8；
能量尺度和初步≤0.1%残差目标继承B03b，并先加入完整1D项。
若新接口适用域达不到预算，不通过该域；不能把域外点删掉只报告成功点。

至少包括一份独立接口参考/制造解，不能仅证明两个模块调用不会抛异常。
正式全部B04验收还需B04b网络和测点，不以本票单管测试覆盖整个人体主动脉。
