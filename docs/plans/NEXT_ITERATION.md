## 1. 本轮目标和边界

本轮目标不是“完成整个 IABP 引擎”，而是给 B04a 建立可信输入并交付一个无球囊、可双向反馈的最小联合闭环。
当前已有连续 0D 原型、独立 1D 小扰动证据和固定观察器；依据见
[STATUS](../STATUS.md)、[B01 报告](../tasks/B01_REPORT.md)、[架构](../ARCHITECTURE.md)。
不要重新实施 B00/B01，不优先扩网页或换语言。复现历史门属于例行基线检查，不将旧任务再次算作新成果。

两条原则：
- 准备工作可并行；接入生产链必须在前置工程门通过之后。
- 数据获取立即启动，但外部数据未就绪不阻止工程切片；缺数据时不得授予生理资格。

1. 读工作规则，执行 `git status --short`、`git rev-parse HEAD`、`git remote -v`。
   若当前 HEAD 比规划基线新，先读新增提交和已有任务报告；不能覆盖并行 Codex 的工作。
2. 确认目标票未被其他分支领取，在 BACKLOG 记录分支、范围与状态。
3. 按下面现有入口复现基线；记录实际版本。缺工具是 NOT_RUN，不是假 PASS。
4. 对选中票先写能失败的测试和输入合同，再做最小实现；勿一口气修改所有模块。
5. 每个切片完成后冻结报告；基础门失败时停在该切片，不以 UI 或调参绕过。

## 6. 停止条件和真正需要决策的事项

| 情况 | 应做什么 |
|---|---|
| 1D 出现负面积、边界特征数不支持或新增伪极值 | 保留失败；缩小声明域或另立数值方案比较，不能截断/平滑掩盖 |
| 能量账本无法闭合或基准回归失败 | 停止耦合接入，先定位遗漏的功/储能/输运 |
| 需要改变“AC”等核心语义 | 保留旧事件，新语义提 ADR，负责人决策 |
| 固定激活方案不足以进入更广工况 | 提供原模型失败证据及最小候选；不擅自改成临床真值 |
| 新依赖、架构更换、临床风险或5 ms目标变化 | 说明替代方案、成本与证据，等待负责人决定 |
| 缺真实传感器/球囊/患者数据 | 继续工程测试，明确不得得出的结论；按B08a追踪 |
| 仅工具/环境故障 | 记录 NOT_RUN；修环境，不改变模型参数 |
