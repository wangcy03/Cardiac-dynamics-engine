# 固定迭代观察器方案

状态：V1 三页范围已由负责人于 2026-10-15 确认；实现尚未开始。
本轮确认范围：心脏/时序、独立 1D、迭代比较三页一起；后续按此范围细化并实现。
本文件是方案，不代表观察器已新增功能，也不改变核心模型或验收结论。

## 建议

保留当前原型的波形阅读方式，把它整理成一个长期维护的查看器。
每次较大迭代新增真实运行数据包与变更说明，查看器读取这些数据；界面源码不随每次运行重新编写。
Wiggers 教学页提供交互和解释层的参考，继续保留原文件。

固定查看器建议三个页签：**心脏/时序、独立 1D、迭代比较**。运行身份、单位、数据来源与适用域共用一个详情面板。

```mermaid
flowchart LR
    E[Python 核心与真实运行] --> R[不可变运行目录\n原始 CSV / JSON / 日志 / 哈希]
    R --> X[固定导出适配器\n版本化查看器数据包]
    X --> V[固定观察器\n心脏时序 / 独立 1D / 迭代比较]
    V --> D[数理原理与事件定义链接]
```

## 为什么当前波形未显示 B01 的变化

现有 `tools/viewer.py` 只读取 0D 演示的八列数据，绘制七轨；绑定 baseline/assisted 两个分支。
四腔压力/容积、瓣膜开口等真实导出已有 33 列，但多数未展示；samples 未载入，commands/provenance 虽内嵌但未展示。

B01 是独立传播器，尚未与 0D 演示耦合。因此原 0D 波形保持不变符合当前架构。
这一轮的变化应在 1D 页看到：传播、反射、分叉、数值方法与网格误差；不能重画 0D 波形制造变化。

## 第一版展示范围

| 页签 | 内容 | 已有数据及边界 |
|---|---|---|
| 心脏/时序 | ECG；LV/Ao/降主动脉压力；流量、容积、球囊；瓣膜开口；PV 轨迹；事件/命令列表 | 使用实际 truth/samples/events/commands；未导出的 R 峰、切迹、动作目标等保持未提供 |
| 独立 1D | 探针压力时序、实际时刻空间剖面、反射/分叉、网格与方法误差 | 读取 B01 原始输出；Boileau 八个时刻是空间剖面，不当作连续时间波形 |
| 迭代比较 | 冻结运行 A/B，波形叠加、原始差值、指标变化、配置/源码差异 | 同场景和统计区间优先；配置、初态或模型能力不同须明确显示，不能自动归因于改进 |

默认轨道保留当前常用信号，其他轨道按主题展开。第一版加入共享时间轴、缩放、双游标、原始采样点、轨道/标记开关。
点击事件或公式名称可跳到正式数理文档对应定义；教学说明只解释已展示数据。

比较维度分别选择：

1. 同次运行的无辅助/有辅助分支。
2. 相同场景的前次冻结迭代/当前迭代。
3. 独立 1D 的方法/网格/参考方案。

默认采用原物理时间、共同坐标尺度，不自动平移波形或归一化幅度。
如以后提供事件对齐的阅读模式，应明确标注对齐事件，保留原时间；缺事件保持缺失，显示对齐不进入验收计算。

## 固定程序与运行数据分离

- 维护固定 `viewer/` 源码，第一版沿用 HTML/CSS/SVG 的轻量结构。`tools/viewer.py` 逐步变为真实导出的适配器。
- 每次运行保存于 `artifacts/runs/<run_id>/`，保留原始 CSV/JSON/日志、manifest 和查看器数据包。历史包不被下一次 demo 覆盖。
- 数据包采用版本化 JSON，可通过文件选择或拖放导入固定页面；在本地 file 模式下也不依赖读取任意相对文件的网络请求。
- 现有 `artifacts/demo/prototype_viewer.html` 保留为兼容的便携快照入口，由同一固定模板和真实数据导出；生成快照不重写查看器逻辑。
- 图形显示可按需要抽样，但测量、窗口指标与导出采用原始精度/原始样本。显示抽样方法和积分区间明确记录。

最小 manifest 包含 schema/run ID、生成时间、Git SHA/dirty 与源码哈希、物理场景/参数/随机源、共享初态标识、方法/网格/积分与输出间隔、通道/单位、时间语义、原始文件哈希、指标定义与统计窗口、能力和未验证项。
当前尚未序列化的跨版本初态不能伪称已证明一致；对应能力随 B02 的可靠快照协议扩展。

## 与教学页的关系

借鉴多轨联动、主题高亮、局部放大、双游标、术语/来源说明和按真实事件产生的阶段色带。
旧页的固定相位、教学切迹/增强峰、心音与浏览器求解器不迁入新观察器。
PV 仅从真实 P/V 导出形成轨迹；不强制闭合，不把过渡窗口称作稳态 PV 环或单搏 SV。

## 未进入第一版的内容

在线调参并重新求解、控制器在线接入、分布式球囊/气动动画、未定义的 R/切迹事件、完整能量账本和临床参考校准。
这些需要对应核心、协议或数据能力，页面可显示未提供。

## 实施顺序与验收

先固定数据包和旧导出适配，接入两份冻结 0D 运行与现有 B01 数据；再做三个视图和联动；最后验证跨迭代、缺失与不兼容输入。

验收重点：换数据包不改查看器代码；旧包可读；原始值/单位/时间与 CSV 一致；窗口指标定义清楚；历史失败/负振铃/缺事件可见；数据/源码不匹配明确提示；同一波形不因切页或缩放被重新合成。
浏览器布局和交互须实际检查，不能只依赖生成或静态检查。

当前工具读取用户指定 file 标签仍被浏览器 URL 安全策略拒绝；本方案依据源代码及导出分析，不声称实际观察了该标签。未以服务器、其他浏览器或间接执行绕过。
