# r2 实现架构及与目标的距离

## 实现范围
r1 是目标，不因当前代码改变。此次实现 M0 调度壳的主要路径、M1 的连续 0D 桥接基准、
以及可关闭的 M2 球囊接口试验。M1 完整验收仍需要一维网络、独立生理资料等，不标为完成。

模型与网页彻底分离。Python 核心可离线运行；HTML 仅消费导出记录。
采用 Python 3.11+ 作为可读、易交接的参考实现，不冻结最终生产平台。性能需要时再建立
C++/其他实现，并逐状态与此参考对照，不能先以语言迁移代替物理验证。

## 模块及依赖
contracts.py：仅可见样本/命令/状态契约，不含真值。
components.py：有单位的解析 RL、松弛、动态开口和阻性本构。
model.py：闭环连续物理状态和守恒输运，不知道传感器、控制器或未来节律。
sensors.py：独立观测链，包括滤波状态和按通道分离的随机源。
engine.py：外生事件、命令队列、采样、交付、连续推进、日志和快照。
scenarios.py：外生节律构造与简单因果控制器。规则示例不作为引擎的正确答案。
examples/run_demo.py：独立评估环境；只把 Sample 和 now_us 传给控制器。
tools/viewer.py：显示导出数据，不计算另一份压力波形。

## 网络
LV → 主动脉根部 → 降主动脉 → 体静脉 → RA → RV → 肺动脉 → 肺静脉 → LA → LV。
连接包括 4 个有有限开口状态的瓣膜和 1 个有惯性的主动脉连接，其余为阻性连接。
所有腔室为有限容积，没有固定左房压力池。暂不含冠脉、壁粘弹性、自主反射和室间耦合。
根部/降主动脉是两集总结点，不是精确几何测点。不存在桡动脉支路。

## 方程（mmHg、mL、s）
心室压 = 被动压力(V) + E_active * a * (V−V0)。
左室被动项：0.05*(V−10) + 0.12*expm1(0.022*(V−10))。
右室使用独立的低阶被动参数。心房主动项由共同房激活状态驱动；还不是独立左右房电传播。
两级激活：c'=(u−c)/tau，a'=(c−a)/tau，在每个相位按解析式更新。
c 是有效代理，不是细胞钙浓度。恢复 r'=(1−r)/0.60，室激活时驱动幅度=0.55+0.45*r，r乘0.5。
这只提供间期记忆，不是已验证 PVC/PESP 模型。

有限开口 z'=7*max(ΔP,0)*(1−z)−12*max(−ΔP,0)*z。
R(z)=Ropen+(20−Ropen)*(1−z)^4，L*dQ/dt=ΔP−R(z)*Q。
Rclosed 有限意味着小量关闭期泄漏；无严格密封等容阶段，不宣称瓣叶接触真值。
恒定有效惯量避免随面积变化的动量项被漏掉。仍需后续动态有效面积/本构校准。
压力、流量、开口分别演化；压差反向时流量可以继续向前。

每个结点：dV/dt=ΣQin−ΣQout。所有连接使用同一个时间积分体积在两端加减。
球囊结点：dVwall/dt=Qin−Qout+dVb/dt，总血量=ΣVnode−Vb。
阻塞因子=(1−Vb/Vsegment)^−2，为定长几何工程近似，不是验证过的环隙阻力公式。
球囊动作是负荷相关的一阶趋近。容量饱和是明示本构边界，压力和血量不截断。

## 数值方法
先做半步预测得到中点压力/开口，再以冻结中点系数进行全步解析 RL 输运、激活和开口更新。
每根动态连接同时返回 Qend 和 ∫Qdt，保证体积转移对称。整体是分裂的中点方案，
不因局部解析而宣称整体精确；以独立 Radau、三步长研究核验。
最大步长初值 250 us；未来 1D 必须另加 CFL 与空间收敛，不能直接沿用该上限。

## 时间与隔离
整数微秒；事件顺序：完成上一连续段 → 电/机械事件 → 预约命令 → 采样 → 交付。
新控制器命令在交付之后提交，最早在下一次边界处理影响状态，不改过去样本。
Sample.t_available_us 表示样本进入可读收件箱的时刻；控制器 callback 的 now_us 是实际批处理时刻。
两者可不同，不能用源时刻代替当前算法执行时刻。
引擎按事件/采样边界细分积分；异步采样配置可能造成微小数值差，须受数值预算约束。
同网格分块调用经过可重复性测试；任意非网格分块的数值一致性需继续验证。

## 快照与内存
完整 deep copy 包含连续状态、开口、激活/恢复、随机源、滤波、交付队列、命令、节律及日志。
仅受信、同版本、同进程对象，不对外加载 pickle。跨进程 JSON/二进制格式和 schema 迁移是 B02。
