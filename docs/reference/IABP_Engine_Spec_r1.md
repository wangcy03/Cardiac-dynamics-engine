## 2. 约 5 ms 的操作性解释

### 2.1 一个目标，四种不同对象

1. **事件估计误差**：估计某个明确事件的时间与其参考时间的差。必须先声明事件是 QRS 起点、II 导联 R 峰、机械关闭、某部位切迹，还是执行器容积阈值。
2. **命令调度误差**：实际交给执行器的命令时刻相对预定执行时刻的差；不包含完整充气时间。
3. **实际动作误差**：实际球囊 10/50/90% 容积时刻或放气残余阈值时刻，相对参考策略目标的差。必须包含已经校准的执行链。
4. **辅助效果变化**：时间扰动带来的舒张支持、心室负担、输出及风险指标变化。它没有统一的毫秒阈值可替代。

r1 将约 5 ms 作为受控、信号可用、链路已标定工况下的目标时间误差量级。拟采用绝对误差的 P50/P95/P99、最大值、带符号偏差以及漏检／误检／不可判断比例共同报告；常规清洁基线的初步目标为 P95 绝对误差不超过 5 ms。这个统计门槛是工程默认，尚不是全工况验收标准；故障、无切迹、未知延迟和不可观测场景不得被偷偷排除后仅报告成功结果。

五毫秒不是最优辅助点的普适定位精度，也不是主动脉瓣关闭生理参考的已证实精度。没有独立参考数据时，只能报告相对于指定模型真值的误差。

### 2.2 初步时间与数值预算（工程默认，不是设备规格）

| 项目 | r1 默认／目标 | 验证条件 |
|---|---|---|
| 直接输入的工程参考 ECG／AP | 各 1000 Hz | 1 ms 采样间隔；各通道采样相位独立可配；不推断真实产品采样率 |
| 求解器基础时间步长上限 | 0.25 ms 起步，可更小或自适应 | 一维 CFL 条件、刚性与事件定位可要求更小步长；不能仅因选了小步长就宣称达标 |
| 关键模型事件的数值误差预算 | ≤0.5 ms | 联合时间／空间收敛与独立参考方案；无事件或拓扑不同需单独判定，不能仅匹配最近峰 |
| 主要压力波形的数值差预算 | ≤0.5 mmHg（r0 继承的暂定目标） | 在相同物理时间比较；不使用时间平移掩盖误差，另报告形态差、守恒残差 |
| 原生软件在环调度量化 | ≤1 ms | 记录样本可用时间、控制器计算时间、命令提交与执行时刻；实际算法延迟可另行配置 |
| 产品／外部通道采样率与交付延迟 | 按具体型号配置；未知为未校准 | 可对 125/250/500/1000 Hz 作降采样故障／敏感性试验，但不能将这些值都当成真实产品设置 |
| 端到端目标 | 约 5 ms 量级，限已声明条件 | 必须同时报告测量、算法、执行器及模型真值不确定性；不能只看算法函数执行耗时 |

这些是分层目标，不是可以简单相加的独立误差项。相关误差、系统性偏差和模型结构误差不得未经分析按均方根合并。需要辨别 ±5 ms 的效果差时，先确认该效果差大于数值与模型不确定度。

1000 Hz 的参考采样是为了减少原型调试时的采样量化限制，不是“1 kHz 就能保证 1 ms 生理精度”。125 Hz 的样本间隔为 8 ms；带形状先验的插值可以给出亚采样估计，但插值本身不能建立独立毫秒级真值。

### 2.3 用效果敏感性验证五毫秒是否够用

在相同快照和相同后续电激活事件序列下，分别对充气与放气安排施加 −20、−10、−5、0、+5、+10、+20 ms 扰动。先做单轴，再做 7×7 二维命令网格；所有组合都必须因果可执行，不能给控制器使用未来心搏事件。

同时输出：
- 实际球囊动作偏差（输入命令差不一定等于实际动作差）。
- 根部舒张压差积分及平均舒张支持；积分区间定义见第 7 节。
- LV 压力时间积分与净外部做功，并联合观察 SV／CO，避免把少射血误判为有效卸载。
- 下一次射血时残余球囊容积、残余阻塞、异常反流及近／远端压力变化。
- 所有上述量的数值及参数不确定度。

输出“时间—效果曲面”和按预先声明阈值得到的可接受区域；不强行生成一个唯一最优毫秒点。在未确定效果容差或风险阈值前，只报告曲面、Pareto 关系与越界代理，不宣布临床安全范围。[N2]

## 3. 多通道输入架构

### 3.1 压力位置、传感器、接口是三个正交属性

每一路 AP 都由以下配置组成：

    取样解剖位置 → 局部真实压力 → 传感／液路动态 → 采集与因果滤波
                  → 量化／采样时钟 → 传输／缓存 → 算法可用样本

头端传感器并不自动位于主动脉根部；头端距球囊和主动脉瓣的位置必须单独定义。外部监护仪既可以接外周液路，也可能有其他压力输入，不能因设备名称自动指定其生理部位。

| 工程通道名 | 数据来源 | 首期行为 | 未校准内容 |
|---|---|---|---|
| AP_TIP_SOLID | 指定头端位置的固态压力链 | 原生参考配置可先用单位增益、已知延迟；另做失真注入 | 实际位置、带宽、零漂、滤波与延迟 |
| AP_FIBER | 指定位置的光纤压力链 | 独立测量链，允许与固态同位或异位 | 实际位置、解调带宽、延迟和漂移 |
| AP_MONITOR | 指定压力输入经过外部监护仪 | 支持单独采样率、滤波、缓存和未知源时间 | 原始压力来源、接口形态、是否提供可信时间戳 |
| ECG_II | 本机电极采集的 II 导联 | 单导联直接采集参考链 | 实际前端滤波和算法处理延迟 |
| ECG_LEADS | 同一电活动的多导联观测集合 | 仅预留接口，未实现通道明确缺失 | 十二导联的电极和导联构造、掉线规则 |

高保真传感器也不是零延迟或无噪声的先验保证。不同链路的定位差异已在 IABP 患者同步研究中观察到；该研究不能提供所有设备的固定补偿值。[N1]

### 3.2 必须通过的多通道一致性试验

**同位、同链路、无噪声**：两路真值与观测应在数值容差内一致。

**同位、不同链路**：真值完全相同，观测差异只来自声明的传感、滤波、时钟和传输配置。

**异位、同链路**：差异由传播、反射和球囊波产生，不允许只是对根部 AP 做固定平移。

**压力单路故障**：其他测量通道的观测不应被同时篡改；但若算法因此改变命令，随后的整个循环允许真实改变。该区分要在开环与闭环各做一次。

**通道切换**：输入候选通道与质量标志供算法使用；选路／融合／补偿属于待测算法或显式基准控制器，不由物理引擎暗中替用户选好。

**未知延迟**：评估器可以知道注入的真值，但算法只能得到真实接口提供的元数据。未知项不能默认为 0，也不能把隐藏延迟以“校准值”自动送给算法。

### 3.3 ECG 的正确扩展方式

首期仅 II 导联，不影响心脏力学核心的范围。其他导联保持未实现，而不是填零后声称真实无电活动。

全导联扩展必须由共享电状态经电极／导联观测产生，不得逐条独立随机生成心搏。仅更改导联、极性、测量噪声或滤波的隔离试验，不应直接改变心室激活；但闭环下算法命令变化可以间接改变力学。

QRS 起点与 II 导联 R 峰分别命名。不同导联的最高峰、最负峰不直接当成新的心肌激活时间。宽 QRS／长 QT 的纯显示变化必须与真实传导／复极病理场景分开；不把人为解耦试验声称为疾病模型。

## 4. 时钟与接口契约

### 4.1 三个时间域

1. 引擎参考物理时间：只向评估器暴露完整真值。
2. 每路设备／采样本地时间：允许偏置、漂移、不同采样相位。
3. 算法可用时间：算法首次收到数据的时刻；只有此时才能作出依赖该数据的决定。

样本记录采集与可用时间。真实外部设备不提供采集时间时，算法可见字段为未知；评估器仍保留真采集时间以计算误差。时钟漂移和传输延迟是两个不同因素。

### 4.2 算法可见信号契约（逻辑定义，不冻结 ABI）

    channel_id, signal_kind, units, sequence_id, value(s)
    t_available
    source_time / source_clock_id（仅当真实链路可提供）
    observable_quality（仅可从硬件接口或可实现估计获得）

算法接口不得带隐藏生理事件、未来采样、真实故障原因、未公开的原始时钟映射或真正的通道可靠度。工程默认量值单位为 AP:mmHg、ECG:mV；求解器内部使用一致单位，所有转换集中管理。

### 4.3 算法输出命令契约

    command_id
    action = INFLATE | DEFLATE | CANCEL_PENDING
    t_issued
    t_execute（可选的未来预约时刻，缺省即尽快执行）
    cancels_command_id（仅取消未开始命令时使用）

命令提交与执行分别留痕。预约基于算法自己的预测，不得由评估器提供下一搏真值。执行器返回 accepted / rejected / started / completed / failed 状态；“completed”仍按声明的设备定义，不等于实际球囊已完全排空。

已经开始的充气不能通过取消命令删除既有容积或压力。反向／紧急排空需要显式放气命令并经过执行器动态。重复、乱序、迟到命令采用可配置设备适配策略；参考适配器可先拒绝无效或过期命令，不冒充真实控制台策略。

### 4.4 同时事件的确定性

在同一时间戳，先完成上一段连续状态推进，再按固定、记录在配置中的事件次序处理外生电激活、先前已预约的执行器命令、采样和样本交付。控制器只能在交付之后计算；其新命令最早影响当前事件处理之后的状态。未来新输入不能改变历史输出。

快照应包括连续心血管状态、瓣膜／球囊／气体状态、各滤波器内部状态、时钟、缓存、预约命令、节律恢复状态及随机源。仅保存心室容积并不构成可复现快照。

## 5. 首版物理核心的范围

### 5.1 采用路线

沿用 r0 的推荐目标：0D 心腔／回流＋低阶电机械状态＋动态瓣膜＋1D 主动脉及必要测量支路＋分布式球囊＋可替换执行器。该路线是工程选择，参数与本构需独立验证；不是用户本轮批准了所有具体方程系数。

持续推进的总状态至少包括：心腔容积、激活与恢复、瓣膜有效开口与流量、血管壁与流动、球囊占据容积、执行器动力学和测量链内部状态。禁用每搏重置和周期曲线平铺作为最终核心。

左心应有主动收缩、松弛、舒张压力—容积本构和负荷／搏间恢复。初步循环拓扑采用有限容积的体／肺循环与低阶右心回流支路，以避免固定左房压力边界吸收所有长期变化。先隔离研究的负荷反馈、压力反射及自主调节须明确开关；首期不承诺长期稳态神经体液响应。

### 5.2 保真度优先级

优先验证的是：电激活→机械张力；压差／流量／瓣膜的非同步；球囊双向排挤和阻塞；下游球囊波与上游心脏波的共同传播；命令到实际动作；多通道可用时间。

先不追求：完整离子通道、三维瓣叶流固耦合、全身三维血管或经验证的氧耗／长期预后预测。可使用更高保真离线模型检查特定降阶假设，但不能用复杂度代替实测证据。

### 5.3 球囊守恒仍是硬约束

    Vblood = Vwall − Vballoon
    dVblood/dt = Qin − Qout
    Cwall · dPtm/dt = Qin − Qout + dVballoon/dt

分布式模型若已用有效过血面积减去球囊面积，不得再把同一排挤量重复计为新增血量。球囊保持膨胀时仍改变过血面积／阻力。负荷相关执行器同时接受局部血压，不得仅由命令时刻播放固定容积动画。

### 5.4 引擎与旧页面的关系

旧教学模式保留。新的 UI 只读取核心日志／流，不为显示另画一条伪“物理曲线”。异常振铃、无切迹、无射血、无可靠事件都应显示真实状态与质量标签，不人为补造漂亮波形。

## 6. 开发顺序与第一批测试

### M0：可验证接口与调度壳

交付：单位与时钟约定、信号链适配器、命令队列、日志与快照、真值隔离、测试入口。先用已知解析信号测试滤波、采样和交付；这些信号不是虚拟患者。

通过条件：因果性、确定性、未知信息隔离、多通道独立、取消／迟到命令与快照恢复测试通过。此时只能称为算法测试基础设施。

### M1：无辅助连续循环

先以解析 RC/RLC 和分叉基准验证元件，再建立心腔、动态瓣膜与已通过独立基准的传播网络。基础窦律、负荷改变和至少一个非周期短联律事件用于确认结构没有按搏重置。

通过条件：守恒、稳定性、时间／空间收敛以及独立多信号基线验证达到声明适用域。若数据尚缺，可运行工程测试，但生理验证不得标为通过。

### M2：球囊与执行器

先规定球囊容积轨迹隔离血液侧，再接负荷相关命令执行器。比较球囊两端压力／流量、占据容积、保持阶段阻塞、充放气动作以及复原过程。

通过条件：台架或合适独立数据支持动作和压力响应。详细氦气／bellow／电机模型暂为可替换层，不能用理想动作接口证明真实执行器精度。

### M3：真实算法、多通道与效果扫描

接待测算法 II 导联与三类 AP 适配器，开展单源、同位多源、异位多源和混合故障测试。用相同快照作参考策略／无辅助／待测算法分叉，输出 ±5/±10/±20 ms 局部效应曲面。

通过条件：输入可用时间与命令时间完整可追踪；完整报告误差、漏检、不可判断和恢复；不允许仅凭 AP 峰值判定效果。

### M4：病理和故障范围扩展

逐步增加 PVC 二联律、房颤、起搏及失夺获、弱搏、高低顺应性、响应变慢、不完全排空等。未校准病理仅列结构／故障测试；不纳入有效虚拟患者统计。首期先做短时机制与恢复测试，不声称复现长期自主调节。

## 7. 效果评价的细化

采用同一参考状态下的多指标，不先冻结一个加权总分。

### 7.1 两种积分时间窗均保留

对照分叉会改变 AC／AO。每条轨迹可以报告自己的机械舒张区间积分，但用于跨策略比较时，另外用参考轨迹定义的共同时间窗计算一份，避免仅因积分窗口被干预缩短而产生“改善”。例如：

    DPTI_self = ∫_[AC_self, AO_next_self] (Pao_root − Plv) dt
    DPTI_refwindow = ∫_[AC_ref, AO_next_ref] (Pao_root − Plv) dt

负压差保留符号，同时可另报正部积分；两者不可混名。此处是压力驱动力代理，不是经验证的冠脉血流或心肌灌注。

同样联合报告：LV 跨壁压做功、LV 压力时间积分、SV／CO、远端流量、残余容积／阻塞、关闭期反向流及异常持续反流。

### 7.2 避免被策略影响的参考答案

实际 AC 与无辅助／参考策略 AC 分别输出。若早充气改变或提前终止射血，不允许用被改变后的 AC 为错误动作“洗掉”误差。

辅助比 1:2 中的非辅助搏仍受上一搏状态影响，不能自动当作未辅助基线。固定快照分叉比较同搏影响；另外独立比较持续运行后的多搏影响。

### 7.3 参考策略不等于可实现算法

可使用真值标注的参考策略检查物理响应，但必须标注 oracle／离线分析。可实现基准控制器只用已交付样本。两者不能混为同类算法进行性能排名。

## 8. 数值、软件与生理验证分层

附带 `verification_plan.json` 给出测试条目、阶段、范围和通过依据。所有条目的初始执行状态为 NOT_RUN，数据依赖事项另列；不把文档完整性校验写成求解器测试通过。

最低通用要求：

- 解析 RC/RLC、零输入能量、管段传播、端部反射与分叉守恒测试。
- 全循环血容量使用含球囊占据修正的体积账本；压力和体积不得靠 clipping 隐藏数值失败。
- 时间步长与空间网格联合收敛，特别检查瓣膜切换和球囊源项附近的人工振铃。
- 单个患者／动物的相邻搏不跨校准和独立验证集合；评分参数在验证时锁定。
- 相同条件重复运行、快照恢复及相同随机流分叉可复现；不同平台数值允许明确容差而非一概要求逐位相同。
- 引擎数值失败、真正无目标事件、传感器质量差、算法弃权分别编码与统计。
- 算法反馈改变后的循环属于真实后果；测试纯测量隔离时须固定命令序列。
