# IABP 定时算法物理引擎：研究依据与设计草案 r0

日期：2026-10-15  
状态：首轮研究与架构提案，等待需求边界确认；不是已实现或已验证的引擎。  
基线：Wiggers v3.2；现有 HTML 未修改。基线 SHA-256 见同目录文件。  
用途建议：成人 IABP 定时算法研发、软件在环调试与受控回归；预留硬件在环。注册支持和临床性能声明需要另外建立证据。

## 0. 核心结论

目标不是生成一组更像真实的 ECG/AP，而是构建**能被 IABP 动作反过来改变、能保留逐搏记忆、能隔离模型真值与算法输入、且可信范围明确的虚拟被辅助循环系统**。

建议的目标模型为：低阶电激活/收缩动力学 + 0D 心腔和回流循环 + 动态瓣膜 + 1D 主动脉/测量支路 + 分布式球囊 + 可替换执行器 + 独立测量链路。先构造可验证的最小闭环，再增加复杂度，不直接从全心电生理或三维瓣膜流固耦合起步。

必须区分两种资格：

- **可用于调试**：能制造已知场景、稳定回放、定位逻辑故障。
- **可用于定量校验**：对目标工况、特征点和辅助干预，已有独立实验验证及不确定度上限。

前一种资格不能自动升级成后一种。第一性原理保证守恒框架；材料本构、心肌激活动力学、节律恢复、仪器动态仍须由实测约束。[S14]

## 1. 现有 v3.2 的复核结论

已检查 `solvePhysicalCore` 与 `computePhysical`。可复用的资产是图文同屏、术语与事件定义、临床对照入口、参数交互，以及压力/容积/流量联动的概念。

但现有核心仍是固定周期解：按 HR 构造单周期，预热至周期近稳态，再通过时间取模查询该周期。左房是给定压力边界；主动脉是近端/远端低阶 RLC 网络；出口采用带惯性的非负流约束。它没有实际球囊状态、球囊沿主动脉的排挤作用、设备执行链和算法在线接口。AC 仍由流量阈值代理，切迹另行检测。

因此：现有页面适合保留为教学与结果浏览器；新引擎应拥有独立、持续推进的状态。原教学模型不能成为新引擎的“正确答案生成器”。现有的“只改 QT 不改力学”适合作为机制隔离实验，但不能直接当作某一种真实药物或疾病场景。

## 3. 第一性原理：先确定守恒与能量路径

### 3.1 系统是两条相互作用的链，而不是一张固定的时序表

内源电激活 → 有效钙激活/张力 → 心室压力与容积 → 瓣膜开闭和射血 → 主动脉传播/反射 → 取样位置压力 → 传感与滤波 → 定时算法。

定时算法 → 充/放气命令 → 执行器/气体输运 → 球囊实际容积和形状 → 主动脉血流与压力 → 改变心室后负荷、冠脉驱动力及后续心搏状态。

ECG 是心脏电活动的观测量，不是实际驱动心肌的信号。R 峰的测量位置、极性、时间会受导联和滤波影响。算法可以因 ECG 质量变差而判断错误，但纯测量干扰不应直接改变虚拟心脏收缩。

### 3.2 球囊是局部容积排挤边界，不是任意的压力加法器

考虑球囊所在一段主动脉。令 Vw 为内壁包围容积，Vb 为球囊实际占据容积，Vblood = Vw − Vb。对于不可压缩血液：

    d(Vw − Vb)/dt = Qin − Qout

若该段的壁容积只依赖跨壁压 Ptm = Pb − Pext，Cw = dVw/dPtm，则：

    Cw · dPtm/dt = Qin − Qout + dVb/dt

该式由体积连续性直接导出。

充气的 dVb/dt > 0 会排挤血液，效果分为近端流动、远端流动和血管壁扩张；放气的 dVb/dt < 0 释放管腔容积并产生降压/回流瞬态。方向和幅值必须由网络阻抗和状态求出，不能固定按 50:50 分流，也不能把 dVb/dt 当成血液注入整个循环的净流量。[S3,S4]

空间表示为：

    Af(x,t) = Aw(x,t) − Ab(x,t)
    ∂Af/∂t + ∂Q/∂x = 0
    等价地：∂Aw/∂t + ∂Q/∂x = ∂Ab/∂t

Af 是有效过血面积。实现中应选定一套面积变量，避免同时减去 Ab 又额外加入同一排挤源而双计数。

球囊保持膨胀时，即使 dVb/dt = 0，过血面积和阻力仍被改变。因此“仅容积流量源、没有阻塞几何”的模型也不充分。球囊位置、长度、局部扩张顺序需要纳入适用域；最小版本可以分段描述而非完整三维网格。

IABP 在一个完整充放气周期不向循环新增净血量，但通过外部机械功和改变压力边界影响心室做功及灌注。能量账本必须包含心肌主动做功、球囊做功、血管储能、血流动能和阻性耗散。

### 3.3 心脏必须对负荷作出反应

建议采用候选框架：

    Plv − Pext = Ppass(Vlv) + Pactive(a, Vlv, dVlv/dt)
    dVlv/dt = Qmv − Qao

最小主动项可采用 a(t)·Eact·(Vlv−V0)，被动项采用可标定的非线性压力—容积关系。a 是有效激活状态，不声称是真实单个心肌细胞的钙浓度。

    da/dt = fa(electrical_state, a, recovery_state, stretch, shortening)
    drecovery/dt = fr(recovery_state, previous_activation)

优先需要的是电激活后有延迟的张力形成、有限速率松弛、前负荷影响、逐搏恢复和必要的负荷反馈，不必首版就求解整套离子通道和三维兴奋传播。

固定时变弹性可作为低阶基准，但不能预先宣称其机械持续时间对负荷完全独立；相关实验已显示传统假设存在局限。[S7] PVC/PAC/房颤场景必须保留 RR 历史、房室关系和收缩恢复，而非复制一搏并拉伸。[S8,S9]

### 3.4 瓣膜和血流惯性决定哪些事件不能合并

候选动力学形式：

    Lv · dQv/dt + Rv(ζ)·Qv + Kv(ζ)·Qv·|Qv| = Pup − Pdown
    dζ/dt = fvalve(ζ, Pup−Pdown)

ζ 表示有效开口状态，Lv 在此候选式中取固定有效惯量；若改成随面积变化的惯量，必须从控制体重新检查动量/能量项。此式是待校准的降阶本构，不是完整瓣叶流固耦合。[S5]

减速时 dQ/dt < 0，因此 ΔP 可以已负而 Q 仍正。必须分别保留：压差反向交叉、流量零交叉、有效开口关闭、A2 声学响应、根部压力切迹，以及各测量部位的切迹。不能用同一 tAC 给所有信号盖章。

正常关闭期可有短暂反向流；闭合后持续反流和瓣膜关闭不全需明确区分。严重主动脉瓣关闭不全可作为禁用/风险识别压力测试，不能将其作为需要优化至“正常疗效”的常规辅助场景。

### 3.5 波传播不能由一个固定时间平移包办

主干动脉建议采用 1D 守恒模型，末端接 0D 阻抗。需包含根部、弓部、球囊段、远端主动脉，并按实际 AP 来源增加测量支路。压力/面积本构及壁黏弹性决定传播、衰减和反射。[S6]

输出必须包含各位置的独立压力。根部未辅助压力平移一段时间，不能替代有 IABP 时的测量 AP，因为球囊波从下游产生、还会与原生前向波叠加。

### 3.6 指令不是球囊动作

沿用项目此前讨论的氦气与约 30–50 mL 球囊方向，但具体 bellow、电机和气路参数不在本稿中强行冻结。

执行器支持三个层级：

1. **规定 Vb(t) 的单元试验接口**：隔离血液侧模型，检查守恒、波传播和反射；不能据此证明实际设备时序。
2. **命令驱动的降阶执行器**：充放气命令、局部 AP、气体/球囊状态共同产生 Vb(t)；分别标定充/放气延迟、爬升、残余容积、负荷依赖和饱和。这是算法闭环测试的建议最低层。
3. **详细气动/机电模型**：接入已有 bellow/电机/氦气模型，求解压力、气体输运、热过程与球囊形变。后续与第 2 层交叉核验。

基础气体关系采用绝压：Pg·Vg = m·RHe·T。瞬态还需质量与能量守恒，不能把不同压力下的气源排量当成相同的球囊排血容积。

    d(m·cv·T)/dt = Qdot_heat − Pg·dVg/dt + mdot_in·hin − mdot_out·hout
    Pg − Plocal = Fmembrane(Vb, dVb/dt, folding_history)

体外研究显示主动脉压力和姿态会影响球囊动作与血液排量。[S4] 因此详细机电模型可以后置，但负荷相关的动作动态不能从正式算法校验中省去。

## 4. 模型层级与边界

### 4.1 建议的正式目标架构

| 模块 | 最小保真要求 | 后续可替换/扩展 |
|---|---|---|
| 电激活与 ECG | P/QRS/T 起止来自共同电状态；导联观测可变；支持非周期事件 | 区域激活不同步、更细胞化动作电位模型 |
| 心肌动力学 | 激活/松弛状态、非线性舒张关系、前负荷与恢复记忆 | 更细肌丝/力—长度—速度模型 |
| 循环 | 有限容积的心房、心室和回流腔室；总血容量守恒 | 右左室相互作用、呼吸、神经体液调节 |
| 瓣膜 | 有限开闭速度、惯性、可追踪有效面积 | 更精细几何/局部流场参考模型 |
| 动脉 | 多位置传播、反射及面积动态；球囊与原生波同一网络 | 个体几何、3D 局部离线复核 |
| 球囊 | 分布式占据容积、阻塞、负荷相关动作 | 轴向展开发生顺序、褶皱和姿态 |
| 测量 | 可独立配置 ECG/AP/BP 导管链路、因果滤波、采样/交付时间 | 外部监护仪转发、模拟接口电路 |
| 评价 | 模型真值隔离、反事实对照、不确定度报告 | 经验证的冠脉/代谢效应指标 |

0D 集总心腔负责压力—容积—充盈；1D 动脉负责传播和形态；3D 只作个别低阶假设的离线检查。初始拓扑可简化，但必须通过分段/网格收敛确定足够空间分辨率，而不是因为“看起来平滑”就合格。

### 4.2 不在首版承诺范围

不承诺精确预测心肌氧耗、梗死面积、患者长期预后或所有瓣膜声学细节。未标定的右心、冠脉和反射调节不可作为疗效结论依据。需要长时间生理漂移或自主调节的试验时，应增加相应状态；关闭反射调节的试验要明确是机制隔离试验，而非完整自主生理反应。

## 5. 算法必须只接触真实可得的信息

建议接口契约：

    advance_to(time, available_commands) -> sensor_samples
    export_truth_for_evaluator() -> sealed_truth_stream
    snapshot() / restore() -> full_continuous_state

这只是接口语义，不冻结编程语言。算法生产接口不包含 truth，也不能查询未来信号或真实下一搏时间。

样本同时记录采样时刻与交付时刻。数字滤波、缓存、丢包、时钟漂移与导管动态分别作用，避免把所有误差塞成一个 τ。

    APmeas(t) = instrument_response[APsite](t) + offset + noise

APsite 由血管模型产生，已经包含生理传播；instrument_response 仅表达导管、传感器与采集链路，不重复加入同一段生理时延。液路可从经过台架标定的二阶动态开始，必要时升级；离线零相位滤波不能偷偷用于在线算法输入。

待测算法命令统一使用明确的绝对时间或相对采样时钟。早搏/信号丢失引发取消、重排、重复命令时，引擎必须保留执行器已有状态，而非瞬时重置为“已排空”。

每次运行记录：模型版本、参数及来源、初始完整状态、节律事件、随机种子、测量链路、算法版本、命令日志、真值日志、质量告警。改变后续的未来节律，不得改变分叉点之前的输出。

## 6. 定时评价的正确对象

### 6.1 必须单独保存的时间戳

QRS 起点、指定导联 R/QRS 参考峰、T 末、张力激活、MC、AO、根部与左室压差反向交叉、Qao 零交叉、AC、根部切迹候选、测量 AP 切迹候选、命令时刻、球囊 10/50/90% 容积时刻、放气后残余容积阈值时刻、根部辅助波到达时刻。

10/50/90% 只是可重复的工程动作定义，不是医学标准。阈值、迟滞与持续时间均写入配置与日志。未检出标为空值，不能回填固定 R+延时。

### 6.2 “最优时刻”不是必然唯一

充气希望形成舒张期有益增压，同时不妨碍尚未完成的射血；放气希望在下一次射血前创造合适卸载，同时避免过早丢失舒张辅助。传播与执行器动态决定命令应提前多少。[S2]

不能把“命令在 AC 后”当成充分条件，也不能把局部球囊开始扩张与根部有害压力到达视为同一时刻。真正需要评估的是球囊动作引起的负荷与血流后果。

输出应同时给出：事件估计误差、动作时间误差、血流动力学效果、未能可靠判断的比例、越界/恢复行为。先输出多目标结果和安全约束下的可接受区域，再讨论是否采用单一加权评分。

### 6.3 推荐量化指标

| 目标 | 指标候选 | 使用限制 |
|---|---|---|
| 电/机械事件识别 | 事件时差、漏检/误检、置信度校准、最差分位数 | 先定义哪个事件，不把 R/QRS 或 AC/切迹混用 |
| 充放气实现 | 指令→实际容积时序、残余 Vb、压力限制/未完成动作 | 使用真实或验证的执行器模型 |
| 舒张支持 | 根部平均舒张压、增压面积、DPTI | 不能单由最高增压峰排名 |
| 左室负担 | LV 峰压、压力时间积分、正向净外部做功、同一状态下的压力变化 | 做功变小可能仅是 SV 下降，必须联合观察 |
| 前向输出 | SV、CO、远端与分支流量、反流量 | 不应假设任何设定下都会提高 CO |
| 危险辅助 | 射血受阻、残余阻塞、逆流、异常低压、高压、失同步后恢复 | 阈值需临床/产品方批准，不能从示意图自定 |
| 稳健性 | 对参数、传感器、节律和模型形式的敏感性 | 不能只在本模型训练过的“漂亮心搏”上成功 |

DPTI 可定义为指定机械舒张区间内 ∫(Pao_root−Plv)dt，必须记录积分区间和负压差处理规则。若没有经验证的冠脉模型，只能称为灌注驱动力代理。[S11]

左室净外部做功以统一循环方向定义，例如正向输出功采用 −∮Plv,tm dVlv。不能混用绝压、表压、跨壁压；也不能把本稿指标称为经过验证的氧耗替代物。

### 6.4 避免参考答案被干预移动

IABP 可以改变实际射血终止和 AC。过早充气可能促使射血提前结束；若只对照“被该错误动作提前了的 AC”，算法可能获得虚假的好分数。

因此每个关键试验保留两种参考：

- 实际辅助轨迹中的动态事件，回答真实动作与当前事件的关系。
- 从相同初始状态及相同外生节律分叉出的无辅助/标准策略轨迹，回答动作造成的变化。

短期分叉比较用于同搏因果效应；持续辅助与非辅助各自稳定后的比较用于累积效果。1:2 中的非辅助搏也可能带有前一辅助搏的状态记忆，不能自动当作完全未干预基线。

未知下一搏在因果算法中不可提前使用。离线 oracle 可以用真值作分析，但须显著标明，不能作为可实现控制器与因果算法直接混淆排名。

## 7. 设计目标与初步验收预算

以下是工程提案，不是已达到的性能，也不是行业规定值。

| 编号 | 目标 | 初始验收方式 |
|---|---|---|
| G01 | 真闭环，辅助可改变本搏及后续搏 | 命令改变后，压力/流量/容积出现连贯差异；状态不按搏重置 |
| G02 | 守恒与被动元件耗散正确 | 每个容积结点有收支；全局血量差采用 Vw−Vb 计算；能量含主动源 |
| G03 | 事件从状态产生 | QRS、瓣膜、流量、切迹、执行器标记分开；不存在固定时刻补填 |
| G04 | 非周期节律有记忆 | 早搏、代偿间歇、突发心动过速不通过整搏时间缩放实现 |
| G05 | 多点测量与在线因果性 | 根部/导管/外周分开；改变未来不改变过去；算法访问不到真值 |
| G06 | 数值误差小于所评估策略差异 | 先提议事件离散误差 <1 ms、主要压力轨迹数值差 <0.5 mmHg；用步长/网格/独立解证实 |
| G07 | 生理误差可量化 | 独立 ECG/LV/AP/流量记录；给出事件偏差、分散和失败比例，不以相关系数替代一致性 |
| G08 | 参数可辨识或不确定性显式传播 | 相同 AP 拟合下，仍检查 LV、流量、SV、事件；保留多组可能参数 |
| G09 | 可重现 | 相同版本、配置、种子、初态得到可重复轨迹及命令结果 |
| G10 | 未验证范围不伪装成功 | 越界工况、未收敛、波形无切迹均显式报告，不截断成“正常波形” |

若用户要比较相差 δt 的策略，建议初始误差预算为数值误差 ≤ δt/10，目标事件总不确定度显著小于 δt，例如先以 ≤δt/3 作为设计讨论值。总不确定度包括测量同步、真值标注、模型结构与参数误差，相关项不能未经分析就平方和相加。

“内部步长 0.1 ms”不等于“生理时间精度 0.1 ms”。原有 125 Hz 压力样本的点间距是 8 ms，插值不能凭空建立毫秒级真值。

## 8. 校验分层

### V0：代码与数学核验

解析 RC/RLC 阶跃与衰减；单位转换；管段波速和端部反射；分叉守恒；零心脏/零球囊输入的能量衰减。使用独立基准，不仅比较本代码不同参数输出。[S12]

### V1：数值核验

至少三档时间步长与空间网格；刚性方程处理；瓣膜事件阈值与插值收敛；不同求解器交叉检查；稳态残差按各状态量的尺度归一化；正反流转变时不得产生人为振铃切迹。

### V2：无辅助生理验证

联合验证 ECG、LV、根部 AP、流量/容积和事件。覆盖不同前负荷、后负荷、收缩/松弛状态和节律。校准与验证按动物/受试者分离，不只把相邻搏随机分组。

### V3：执行器与球囊台架验证

同步记录命令、bellow/气源状态、气压、Vb(t)、球囊两端血液压力/流量；扫描 AP、充放气持续时间、管路阻力、角度、容积与不完全排空。压测的“压力”须明确绝压/表压和传感器位置。[S4]

### V4：辅助效应验证

在受控台架或合适的实验资料下，比较正确时序、早充气、晚充气、早放气、晚放气、不同辅助比及切换过程。要求参数在验证中冻结，不能每个时序重新拟合。

### V5：算法验证

在已通过 V0–V4 的适用域内接入真实算法，运行失同步、变节律、噪声和执行器异常。数据集锁定、统计按受试者或独立工况分层，汇总偏差、尾部风险和恢复能力。

通过 V0/V1 只能说明方程被正确求解；通过 V2 也不能证明 IABP 耦合正确。未经 V3/V4 的模型只能作为辅助动作调试环境，而不是设备有效性的定量校验依据。[S14]

## 9. 首批工况矩阵

基础生理：稳定窦律；HR 改变；低/高前负荷；低收缩性；松弛延迟；高外周阻力；高/低主动脉顺应性。具体生理范围与变量相关关系待来源/产品适用域锁定，暂不把滑条范围当成人群范围。

节律：PAC、PVC、二联律、代偿间歇、房颤、起搏与失夺获、突发快/慢节律。针对 PVC，保留前后搏恢复和充盈，不能只改 ECG。

测量：导联反相、低 R/高 T、噪声与基线漂移、工频、起搏尖峰、压力欠阻尼/过阻尼、冲洗伪迹、漂移、削顶、丢样、时间戳/缓存延迟、外部 ECG/AP 不同步。[S10]

辅助：停泵、1:1/1:2/1:3、辅助比改变、主动错时、响应变慢、不完全充气/放气、缺失/重复/取消命令。球囊充气可能遮盖天然切迹，算法不应把每一搏都假设成有清晰自然切迹。

病理边界：宽 QRS、机械不同步、弱搏无明显压力脉搏；严重瓣膜病单独列为边界/风险识别用例，未经验证不作疗效优化对象。

故障注入与生理采样分开：不符合生理相关性的信号组合仍可用于软件鲁棒性，但必须标“工程故障场景”，不作为真实虚拟患者统计。

## 10. 数据优先级与缺口

### 10.1 已找到的外部来源

- 无辅助中央高保真基线：Avendaño/Midgett 等公开论文声明提供原始 ECG、主动脉/LV 压曲线及分析，入口 Zenodo 7568888。动物、开胸和病理背景须独立分层。本轮未取得并核验原始文件，不能列为已经可用的校准集。[S13]
- 人体中央 AP：Tamborini 等研究有 115 名入选受试者、3,615 个波形，但数据使用受协议约束；公开代码不等于原始数据开放。该研究还排除了严重心律不齐等数据，不适合作为全覆盖节律基准。[S15]
- IABP 介入响应：优先参考 Schampaert 等模型/患者调整时序、Pantalos 等多点时序、Biglino 等球囊动作实验。论文摘要和结果可提出验证目标，但不是可替代原始时序数据的真值文件。[S1–S4]
- 数值传播：Boileau 等公开基准有输入、实验与多方案解，适合求解器核验。[S12]

### 10.2 最有价值的同步数据组合

共同采集时钟下：原始 ECG、根部高保真 AP、LV 压、球囊附近 AP、算法实际 AP 输入、主动脉流量、充放气命令、实际 Vb(t) 或经独立标定的容积代理、气源/球囊气压。能够获得瓣膜影像或其他独立瓣膜参考则更好。

并非每个动物/患者必须具备所有通道，但至少需要覆盖：无辅助基线、辅助开启/关闭、时序变化、不同生理负荷。仅有无辅助 AP 即使切迹很漂亮，也不能识别全部心肌、血管、执行器参数，更不能验证 IABP 的反事实响应。

若第一阶段只能获得台架数据，应明确：台架用于验证设备和血液侧耦合，不会自动完成人体生理验证。

## 11. 开发顺序和停止门槛

**D0 需求冻结**：确定实际 AP/ECG 来源、算法输出边界、最小需要分辨的时序差、研发/注册用途、首批病理范围。冻结事件词典、单位/时钟与校准/验证分组规则。

**D1 无辅助核心**：持续状态的心脏/循环 + 动态瓣膜；先用简单动脉负载核验，再接已通过基准的 1D 动脉。达到守恒、因果性和无辅助多信号一致性后进入下一步。

**D2 血液侧球囊**：规定 Vb(t) 接口隔离物理，验证排挤、双向传播、阻塞和关停恢复；再接降阶负荷相关执行器。未通过台架动作验证，不宣称命令级精度。

**D3 真实测量链路与算法**：因果采样、导管/滤波、日志、命令接口、快照分叉；所有可视化由同一状态输出，不另造“好看曲线”。

**D4 非周期节律与鲁棒性**：逐搏恢复、PVC/房颤等；不使用周期解平铺。锁定测试集，做时序/效果/失败恢复三类回归。

**D5 提升可信度**：独立实验验证、参数/模型结构不确定度、可选详细气动模型与硬件在环。正式用途变化时重新评估模型风险。[S14]

现有 Wiggers 页面保留，不在本轮重写。新引擎的核心验证不依赖网页动画；页面后续只消费引擎输出并保留教学/临床模式。

## 12. 需要用户决定、不能替代用户猜测的事项

| 决策点 | 建议默认方案 | 为什么影响架构 |
|---|---|---|
| 实际 AP 来源与设备测量链 | 按真实设备配置；模型内部同时保留根部和取样点压 | 决定血管支路与仪器动态，不可把根部压默认当算法输入 |
| 待测算法输出 | 以带时间戳的充/放气命令为边界；命令以下有负荷相关执行器 | 决定是仅验证调度还是验证最终球囊动作 |
| 用途级别 | 首版研发/软件在环，预留硬件在环；注册证据另立目标 | 决定证据、质量控制和校验深度 |
| 时间分辨目标与关键工况 | 用户给出需要区分的策略差值及首批必过场景 | 决定数值/同步/数据真值的误差预算 |

尚未决定的界面细节、框架和文件格式不应拖延生理模型设计。具体评分权重也可以在先建立多指标输出后讨论。

## 13. 结论

最低可信路线不是“给旧 RLC 图加一个气球”，而是保留以下因果闭环：电状态→张力→心室/瓣膜→传播网络；算法命令→实际 Vb→网络负荷→心室；网络测量→算法。任何跳过此闭环的捷径，都要标明它只能验证哪一层，而不能验证哪一层。

首轮建议采用多保真、模块独立但共享状态的方案。先把可测、可守恒、可对照的对象定义好，再开发。真正的里程碑不是做出切迹，而是解释并预测切迹、充放气效果和算法失效何时会出现、何时不会出现。
