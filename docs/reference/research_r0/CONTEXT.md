# IABP 定时物理引擎：领域词典（设计草案 r0）

状态：2026-10-15 研究与需求讨论稿；不是已批准规格。

## 时间与事件

- **电激活事件**：心房或心室组织去极的生理事件；不等于某一心电导联的波峰。
- **R 峰**：指定 ECG 导联中规定的正向 QRS 波峰；负向主导 QRS 应另称 QRS 参考点。必须注明原始或测量通道。
- **AO**：主动脉瓣开放事件。记录开放起始、有效开口形成等操作性定义，不把它们无条件合并。
- **AC**：主动脉瓣关闭事件。模型的有效开口关闭判据是模型真值，不自动具有临床瓣叶关闭金标准地位。
- **Qao 零交叉**：主动脉瓣净流量的前向流终止点；不强制等于 AC。
- **压力反向交叉**：左室与根部主动脉压差由正变负的事件；由于血流惯性，此时仍可能存在前向流。
- **重搏切迹**：压力波形中的形态特征。切迹起点、谷底和导数特征必须分别定义；注明测量位置和通道。
- **压力 P2**：收缩期第二压力峰或晚收缩肩部的形态称谓；不能强制每搏出现。不同于心音中的肺动脉瓣关闭成分 P2。
- **充气命令时刻**：控制器请求充气的时刻；不同于球囊开始扩张、达到规定容积、根部感受到压力效应的时刻。
- **放气命令时刻**：控制器请求放气的时刻；不同于球囊开始回缩或达到规定残余容积的时刻。
- **生理时刻 / 采样时刻 / 交付时刻**：物理事件发生、传感器采样、样本交付算法的三类时间；不可混用。

## 物理量

- **球囊实际排血容积 Vb**：球囊及其不透血结构占据血管腔、排除血液的实际容积变化；不同于气源排量、标准状态气体体积和标称容积。
- **球囊变化率 dVb/dt**：球囊对局部血液产生的容积排挤/释放速率；不是血液进入循环的外源净流量。
- **血管壁包围容积 Vw**：血管内壁包围的总腔内容积；有球囊时血液容积为 Vw−Vb，并需统一计入导管杆占据的固定容积。
- **根部压 / 局部主动脉压 / 测得 AP**：主动脉根部血液压力、球囊或取样部位压力、经测量链路后的算法输入；三者不等同。
- **球囊气压**：球囊内部气体压力；须注明绝压/表压和取样位置，不等同于主动脉血压。
- **模型真值**：仿真内部按已声明定义得到的状态或事件；可用于自洽检查，但不等同于已经验证的患者真值。
- **校验参考**：独立实验、临床测量或独立数值解。须附不确定度、同步方式、测量链路与适用范围。

## 评价

- **时序正确性**：算法决策、执行器响应与预定生理目标窗的对应程度。
- **血流动力学有效性**：辅助动作对负荷、压力、流量和容积所产生的效果，不能仅由时序误差推断。
- **反事实基线**：从相同初始状态和外生节律输入出发、改变辅助策略而得到的对照轨迹。
- **DPTI**：按规定舒张期区间积分主动脉根部压与左室压差所得压力时间指标；只是灌注驱动力代理，不等于冠脉流量或氧供。
- **校准集 / 验证集**：用于参数选择的数据与用于独立检验的数据；同一受试者的相邻心搏不作为独立人群验证。
- **适用域**：已有证据支持模型判断的患者、设备、信号与运行条件集合。
