模型身份与限制

电学与机械采用不同的状态描述

ECG 只提供可审计的 P、QRS、QT 起止点，幅值是示意。机械激活时间从 QRS 起点加给定延迟计算；不把 T 末当成关闭开关，也不把宽 QRS 自动解释成机械不同步。

新增物理核心：近端惯性与弹性联动

P_lv = E(t) · (V_lv − V0) Q_mv = max[(P_la − P_lv)/R_mv, 0] L_a · dQ_a/dt = P_lv − P_root − R_ao·Q_a Q_a ≥ 0：理想无反流瓣膜约束；不是压力或容积裁剪。 dV_lv/dt = Q_mv − Q_a C_root · dP_root/dt = Q_a − Q_link L_link · dQ_link/dt = P_root − P_dist − Zc·Q_link C_dist · dP_dist/dt = Q_link − (P_dist − P_v)/R_s

显示的主动脉压力就是求解状态 P_root，不另加装饰性高斯峰；其变化会反馈到出口压差。

C_root = 0.12 mL/mmHg C_dist = Ca − C_root L_a = 0.00008 mmHg·s²/mL L_link = 可调，默认 0.0008 mmHg·s²/mL Zc = 0.055 mmHg·s/mL P_v = 5 mmHg；V0 = 10 mL P_la(t) = Pla基线 + 2.8·exp[−0.5((t−心房驱动中心)/25ms)²] E(t) = Emin + (Emax−Emin)·归一化双Hill激活函数 f(u) = [(u/τrise)^1.9 / (1+(u/τrise)^1.9)] / [1+(u/τfall)^21.9] 激活波按每搏重复，在周期末平滑回到零。 τrise、τfall 随 (72/HR)^0.35 缩放，属于模型假设。

数值使用 RK4，默认约 0.5 ms 步长，最多 80 搏预热至周期状态差小于 10⁻⁵。只有理想瓣膜的非负出流约束，不用压力/容积上下限掩盖发散。单搏积分结果单独校核。

为什么这仍不是真实瓣膜切迹的完整模型

该低阶 RLC 网络允许弹性储能、血柱惯性及局部回摆，比二元 Windkessel 多了瞬态自由度。但它没有瓣叶几何、接触、涡流、短暂反流与分布式动脉波传播。因此局部谷底只叫“切迹候选”，不能当临床瓣膜关闭真值。

本版在 AC 前 8 ms 至后 65 ms 搜索局部谷；其后 60 ms 内须出现局部峰且回升超过 0.15 mmHg。否则报告“未检出”。这些是本页候选算法参数，不是医学标准。

流量阈值 0.1 mL/s 并检查约 8 ms 持续性，用于标注模型 AO/AC。未检出不补固定时刻。P2 仅按射血窗内局部极大值检出，不做真实前向/后向波分离。

教学模式

教学模式使用有限支持 ECG 波、事件定义的压力形态和单调容积变化。等容期容积保持不变，射血流量与容积由积分对应。压力仍为构造波形，不应把教学峰位置当作 ODE 结果。

当前模式说明

教学模式：形态学合成

ECG ≈ 多个 Gaussian 波包叠加（P / Q / R / S / T） AoP(t) ≈ baseline_runoff + ejection_rise + P1 + optional P2 + incisura + dicrotic rebound LVP / LA / Flow / Volume ≈ logistic(sigmoid) 过渡 + Gaussian 局部峰/切迹 用途： - 适合讲解完整时序 - 适合概念学习与特征点理解 - 不要求严格满足血流守恒与压力-容积联动

物理模式：半物理模型

核心方程： 1) 左室时变弹性 P_lv(t) = E(t) · (V_lv(t) - V0) 2) 瓣膜压差逻辑 Q_mv = max((P_la - P_lv) / R_mv, 0) Q_ao = max((P_lv - P_ao) / R_ao, 0) 3) 左室容积连续性 dV_lv/dt = Q_mv - Q_ao 4) 2 元 Windkessel 动脉模型 C_a · dP_ao/dt = Q_ao - P_ao / R_s 5) 反射波 / augmentation（简化） P_reflect(t) = A_aug · exp(-(t-μ)^2 / 2σ^2) P_ao,display = P_ao + P_reflect 备注： - 左房压在本页仍为教学近似，并未完全纳入独立顺应性腔室方程。 - 因此物理模式是“半物理”，重点在于把收缩性、后负荷、顺应性与波形联动起来。
如何理解两种模式：
教学模式更像“示意图引擎”，物理模式更像“可交互的半物理仿真器”。前者让你快速理解知识结构；后者则更适合理解参数变化对波形的影响，比如后负荷升高、动脉顺应性下降、收缩力变化等。

缩写与测点先明确

本页用 AoP 表示主动脉压力，ABP 表示动脉血压通道。AP 在部分脉搏波分析论文中另指 augmentation pressure（增强压），不是整条主动脉压力曲线；例如上方 PNAS 论文即采用这个用法。中央升主动脉测量比部位不明的外周 ABP 更切题，但仍应核实传感器距瓣口位置和记录链路。

图中的独立轨道方便读图，但比较瞬时 LV/Ao 压差时，请在参数页启用同轴压力叠加，不能直接比较两个不同纵轴上的屏幕高度。

高保真筛选不只看采样率

应核实传感器是否位于升主动脉/根部，是否为尖端固态微压传感器，压力与 ECG 是否共时钟，是否保留原始采样与滤波说明，以及零点、漂移和导管频响。高采样率的液柱导管曲线也可能存在过冲或阻尼失真。

切迹应同时检查与出流终止、中央压力变化的关系；算法找到谷底不自动证明瓣膜关闭。独立超声或流量参考，比用同一条压力信号反过来证明自己的标注更有价值。

真实记录与示意模型对照

ABP 不是已确认的主动脉根部压力。本片段未注明具体导管部位，也没有逐通道延迟标定或同步瓣膜事件真值。适合学习真实形态与测量方法，不可用来校准 R→AO / R→AC 的生理时延。

与前两种模式如何对照

先电后机械：逐搏视图以本搏 ECG 参考峰为零点，观察随后出现的 ABP 上升脚、主峰与下降段。测到的是“记录通道之间的间隔”，不是射血前期 PEP。

压力波 P2 不一定独立成峰：本页没有人为加入第二个高斯峰。平肩、单峰、小凹点和噪声均保留；不能把任意肩部直接命名为 P2，更不能把切迹后的重搏波叫作收缩期 P2。

并非每条轨道都来自实测：本页只显示数据文件实际提供的 ECG、ABP，以及记录 A 的 PAP / PLETH。没有测得的左室压、左房压、容积、流量和心音不补画为“临床波形”。PAP 是肺动脉压，不是左房压。

切回原模式：顶部“教学模式 / 物理模式”仍保留原先的参数、文字与交互；本页的导联、视图和测量状态独立保存。对照的是现象与定义，不是病人级拟合或模型验证。

研究依据与采样说明见“来源与限制”。

推荐的观察顺序

先看连续片段，再逐搏放大。记录 A 首选 III 导联；切到 I 导联观察干扰为何会误导检测。最后看多搏叠加：各搏只平移对齐 ECG 参考峰，不拉伸 RR、不归一化幅值，保留真实逐搏差异。

v3.2 时序提示：后段凹点候选不是确认的主动脉瓣关闭。本记录 +518 ms 的候选尤其不能直接套用到主动脉根部；请在“时序校核”对照其检测定义、测点和设备延迟。

显示控制

关闭标记会同时隐藏文字、圆点与引线，不隐藏波形。凹点仅在存在明显局部回升时提示；未检出就留空，不强制给出 AC 或 P2。

双游标测量

在左图点击取时；游标吸附 2 ms 显示网格。ABP 数值来自邻近 8 ms 采样点，不能因此声称压力时序精度达到 2 ms。多搏叠加时游标读取当前选中搏。

尚未设置两个游标。

本页标记的来源

标记由本页针对这两段短记录的启发式检测产生，不是临床专家标注。ECG 正/负峰用极性与不应期筛选；上升脚取最大上升斜率前约 100 ms 内的局部低点；SBP 取随后主峰。脚部压力作为近似 DBP，未必等于整个电学周期的绝对最小值。

没有用 ECG 自动推断二尖瓣开闭、主动脉瓣开闭、QT 或 P 波边界。记录 A 换导联后仍使用 III 导联参考点；记录 B 的负向参考峰不改称正向 R 峰。

数据谱系与取样位置

为什么选这两段

选择的是公开 ICU 数据中 ECG 和脉动压力均可辨识的短片段，不是“健康正常值”或经专家审定的标准 Wiggers 图。记录 A 的 III 导联较干净，I 导联仍有干扰，刻意保留作信号质量对照；记录 B 展示负向 QRS 与另一种压力形态。

原始 MIMIC 保存 500 Hz、12-bit ECG。该优势并不等于所有通道已消除硬件和滤波延迟，也不代表这里的压力幅值已通过独立标定。数据集说明 [1]

这些片段的压力值偏低，只按原文件增益显示。不能只凭几秒记录认定病因、休克或传感器是否校准正确。

时序和形态的边界

125 Hz 压力通道的采样间隔为 8 ms；低通滤波、管路响应和测量部位可影响脚部与切迹。未校正的 ECG→ABP 间隔混合了电机械过程、脉搏传播和设备链路延迟，不能直接填进主动脉根部延时表。

MIMIC-III 官方另有“通道间未知时延最高可达 500 ms”的警告。本页用的是更早的原始 MIMIC，不能把这条数值原样套用，也不能由此反推原始 MIMIC 完全没有延迟。MIMIC-III 技术限制 [3]
