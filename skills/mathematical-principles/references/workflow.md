# 推导与证据维护的通用流程

## 从物理对象到可解释实现

先建立最小对象表：系统边界、可积累的状态、跨边界的交换量、源/汇、输入和可观察输出。
热学项目可能积累内能，RC 电路可能积累电荷；不要跨项目照搬状态、单位或阈值。
先问“什么量会积累、通过什么路径交换”，再决定相应的守恒或平衡关系。

对每条方程逐步记录：

1. 用一个具体机制说明变化原因，例如“输入大于流出时，存量增加”。
2. 写连续关系，明确微分对象、符号和正方向。
3. 用本构或闭合关系把不可直接求解的量连接到状态，声明其经验性与适用域。
4. 做量纲检查；若混用单位，指向集中转换入口和对应检查。
5. 写初始条件、边界条件和参数来源，包括哪些为工程假设。
6. 映射到实际代码中的状态、导数/通量、边界、积分器和失败路径。
7. 说明数值法近似了什么，稳定约束是什么，有什么误差或耗散。
8. 指向真实数值研究与未覆盖区域；没有证据就保留缺口。

读者应该能沿“机制 → 式子 → 单位 → 代码 → 证据”找到同一个对象。
公式在代码里出现并不证明它来自基本定律；经验项、拟合项和人为驱动单列。

## 时间、边界与失败

离散方法说明实际阶段时刻和权重，而不只写方法名字。
守恒账本应使用实际进入更新的通量与源项，避免对不同阶段的量重复计入。
耦合接口写清交换量、方向、取值时刻、单位、可见状态和失败后是否提交状态。
有实时控制时，区别物理发生、源时间戳、样本可交付、算法决策、命令与动作。
不能从内部真值读取能力推定外部算法也有相同信息。

失败判据使用可观察条件：非有限状态、违反本构域、守恒残差超限、根求解未收敛、
不满足稳定约束、事件拓扑不符、证据身份不符等。门槛来自项目已定规格或明确论证；
不要为了得到绿色报告而改门槛或逐工况调参。

## 有界证据适配器

优先复用项目已有工具。新适配器只处理已知的少量文件和明确的字段：

1. **输入契约**：列路径、schema、必需/可选字段、单位、轴和允许的范围。
2. **读取**：只读真实导出；JSON 类型不符、CSV 必需列缺失、时间不递增或数值非有限时显式失败。
3. **身份**：对原始字节计算 SHA-256；保留运行记录中的配置/源/数据/日志身份，不补造运行来源。
4. **派生**：仅计算事先说明的指标，例如实际时间差上的积分；在文档写定义和单位。
5. **展示**：缺失文件为 `NOT_FOUND`，缺字段为 `NOT_RECORDED`，不同身份为 `DIFFERENT`。
6. **写入**：确认唯一且有序的证据标记，只替换其内部；先在内存生成，异常时不写半成品。
7. **检查**：提供只读 `--check` 比较派生内容；陈旧非零退出，与模型验收状态分开。

不自动执行求解，不修改参数或任务状态，不把任意键名猜成通用指标。
适配器若需要新增依赖，说明必要性并遵守项目依赖边界；简单读取与生成使用标准库即可。

推荐为每条证据保存如下含义，而不是强制所有项目使用同一 JSON schema：

| 类别 | 应表达的信息 |
|---|---|
| 历史运行 | 运行时记录的源/配置/输入身份、命令、退出码、环境与时间 |
| 本次读取 | 原始路径、当前字节哈希、读取时的当前源身份 |
| 数值结果 | 原始指标、单位、误差定义、阈值与局限 |
| 对照关系 | 可比条件、匹配/不匹配、缺失身份、不确定性 |
| 图 | 输入身份、绘图工具/版本、观察窗、采样与预处理 |

只读取到当前源码时，可以说“当前文件 SHA-256 为 …”；不能说“这次历史运行由该代码生成”。

## 版本与可比性

保留旧结果和失败说明，用版本化路径或 manifest 明确身份；更新索引不覆写历史原件。
对照必须明确输入、初态、边界、单位和观察窗。不能把网格剖面当时间轨迹，
不能把短窗口积分叫作稳态单周期量，也不能用当前已改阈值回写旧版本的通过状态。
若配置不同，只能按项目已有可比性约定比较；没有约定则先显示差异与不可比原因。

## 检查结果的含义

`check_document.py` 的 `PASS_STATIC_ONLY` 表示受检文件满足其离线静态契约。
它不判断推导是否正确、LaTeX 与 MathML 数学上是否等价、曲线是否真实、模型是否稳定，
也不提供浏览器渲染、数据 freshness、数值验收或适用性结论。
MathML 注解与折叠源码的文字差异会产生警告，需要人工核对，不能据此自动改写公式。
既有文档完全没有本技能的证据标记时只警告该边界未评估，保留项目原有刷新器和标记；
若使用本技能标记却单边缺失、重复或逆序，则检查失败。公式后的 `details/pre` 可以是同父的
紧邻兄弟节点；不能越过其他正文或公式寻找远处的源码来补配。

检查器允许 HTTP(S) 学术导航链接但不访问它们；远程嵌入、脚本、网络样式/字体不允许。
允许本地样式与图片，检查其存在和本地依赖；内联 SVG 的语义替代文本需齐全。
它不是恶意 HTML 的安全沙箱或完整 HTML/CSS/LaTeX 验证器；发布不可信内容仍遵守项目安全边界。

浏览器检查失败或被策略拒绝时记录实际原因并交付静态成果，不尝试规避明确禁止的入口。
软件测试通过只支持它覆盖的实现行为；物理/临床等结论需要各自独立证据。
